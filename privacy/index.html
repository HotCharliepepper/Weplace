1. 운영 주체와 문서 범위

Weplace의 기존 공개 표기에 기재된 서비스 운영 법인은 (주)위플레이스마케팅입니다. 이 초안에서는 기존 표기를 대조용으로 사용하며, 최신 사업자등록증과 실제 운영 담당자의 확인이 끝난 정보로 표시하지 않습니다.

홈페이지 체험·자가진단·미팅 준비와 FLOW의 가입·로그인·매장 연결·공유 업무·작업 의뢰를 함께 검토합니다. 상담 채널과 직원 CRM, 공개 기록, 호스팅·분석·인증 서비스도 별도의 처리 흐름으로 확인합니다.

Mashcore 연결은 관점과 기록을 소개하는 콘텐츠 링크입니다. 이 패치에서 고객 계정 통합, 상담 기록 복제, 고객 정보 자동 전달을 구현하지 않습니다. 두 브랜드의 법적 역할이나 위탁 관계는 별도로 확정해야 합니다.

2. 처리 목적과 항목

아래는 소스에서 확인한 처리 구조입니다. 실제 운영 계정의 설정과 현재 저장된 고객 내용을 조회한 결과는 아닙니다. 각 목적의 필수·선택 항목과 실제 운영 여부를 확정해야 합니다.

구간·목적확인한 항목·처리확정할 내용
고객 시선 체험·자가진단·미팅 준비업종, 방문 목적, 선택 답변과 준비 요약을 브라우저 메모리에서 처리합니다. 직접 복사·내려받기를 선택할 수 있습니다. 답변을 자동으로 상담·CRM에 전송하거나 저장하지 않습니다.접속 기록·분석 계층은 이 응답 처리와 별도로 확인합니다. 이용자가 저장한 파일·클립보드는 이용자 기기에 남을 수 있습니다.
카카오·이메일 상담이용자가 해당 채널에서 직접 보낸 연락 정보·매장 설명·상담 내용이 해당 채널로 전달될 수 있습니다. 링크를 누르는 것만으로 문의가 접수되지는 않습니다.담당자가 별도 업무 도구로 옮기는 항목, 접근자, 보관·삭제 방법과 적법 근거.
FLOW 가입·로그인소스에는 Netlify Identity를 이용한 이메일·비밀번호 입력, 인증 확인, 복구와 프로필 처리가 있습니다. 계정 식별자와 프로필 표시명 등을 업무 권한에 사용합니다.실제 인증 설정, 공급자 처리 항목, 필수·선택 구분, 로그와 계정 삭제.
내 매장 연결인증 계정, 매장 연결 권한과 연결 코드의 검증 정보를 사용합니다. 고객 연결 권한은 직원 팀 권한과 구분됩니다.연결 종료 뒤 기록 보유 기준, 만료 코드 정리, 탈퇴·권한 회수 절차.
공유 업무·작업 의뢰제목·내용·희망일·링크·상태·답변과 작성자·시점 등을 처리하는 구조가 있습니다. 의뢰 제출은 실제 FLOW의 인증·권한 확인 뒤 이루어집니다.자유기재에 포함될 제3자 정보의 제한, 필수·선택 항목과 업무별 보유·삭제 기준.
직원 업무·CRM매장과 고객 담당자 정보, 연락처·관계 메모·계약 정보·상담 기록 및 직원 업무·일정 관련 필드가 있습니다. 권한에 따라 열람 범위를 구분합니다.실제 사용하는 항목, 수집 출처·근거, 담당자·직원 정보의 분리와 보유 기간.
프로필 사진·공개 사례FLOW에 프로필 사진 저장과 공개 기록 승인·철회 구조가 있습니다. 공개 사례에는 별도의 공개 검토가 필요합니다.사진 원본 삭제와 백업, 이미지·브랜드·개인정보 공개 권한, 철회 뒤 보관 기준.
분석·보안·접속 기록기존 운영 GA4와 호스팅·인증 계층이 있습니다. 신규 퍼널 계측은 기본 꺼짐 상태이며, 진단 답변 원문을 분석 이벤트에 넣지 않습니다.실제 쿠키·온라인 식별자·접속 기록, 공급자 설정, 보관·국외 처리와 거부 방법.

가상의 테스트 자료만 사용하는 신규 상담 인입 검토 코드는 실제 고객 저장·발송 기능이 아닙니다. 이 초안이나 새 footer를 추가해도 자동 인입은 활성화되지 않습니다.

3. 처리 근거와 수집 시점의 안내

처리방침 링크나 문서 전체에 대한 일괄 동의가 모든 처리의 근거를 대신하지 않습니다. 상담, 계약 이행, 계정 운영, 보안, 선택적 홍보 등 목적별로 해당 근거와 필요한 범위를 검토합니다.

동의를 근거로 수집할 경우에는 실제 수집 시점에 목적·항목·보유 기간·거부권과 필요한 불이익을 구체적으로 안내하고, 선택적 홍보를 필수 서비스와 분리해야 합니다. 이번 패치는 새 동의 체크박스나 수집 기능을 만들지 않습니다.

각 처리에 어떤 근거를 적용할지는 운영 책임자의 확인 전입니다. 특히 직원이 기존 상담 내용을 CRM에 옮기거나 다른 서비스로 전달하는 과정은 별도로 확인해야 합니다.

4. 보관·삭제·백업

보유 기간을 일괄적으로 정하지 않았습니다. 상담·계정·업무·계약·보안 목적별로 기간과 근거, 별도 법령에 따른 보존 여부, 분리 보관과 접근 제한을 확인한 뒤 확정합니다.

  • 진단·미팅 준비 응답: 웹페이지 메모리에서 처리하며 새로고침하면 초기화됩니다. 직접 복사하거나 내려받은 내용은 이용자가 관리합니다.
  • FLOW 연결 해제: 고객의 조회 권한을 회수하는 동작입니다. 기존 업무·계약·상담 기록 전체의 삭제를 뜻하지 않습니다.
  • 공개 기록 철회: 공개 노출을 중단하는 상태 변경이며 원본 기록의 파기와 구분됩니다.
  • 프로필 사진 삭제: 현재 검토한 소스에서는 프로필의 사진 연결을 지우는 동작이 확인됐습니다. 저장된 사진 파일과 이전 버전의 영구 삭제까지 완료된다고 안내할 수 없습니다.
  • 탈퇴·파기·백업: 인증·데이터베이스·사진 저장소를 함께 처리하는 삭제 절차, 백업 잔존 기간과 복구 후 재삭제 방법은 운영 확인이 필요합니다.

운영 담당자가 항목별 파기 방법과 수행 책임자, 예외 보존 근거를 확인하기 전에는 즉시 영구 삭제나 특정 기간 내 완전 삭제를 약속하지 않습니다.

5. 위탁·제3자 제공·국외 이전

소스에서 확인한 서비스는 Netlify의 호스팅·Identity·Database·Blobs와 기존 Google Analytics입니다. 상담은 카카오·이메일 등 이용자가 선택한 별도 채널로 이어질 수 있습니다. 업무용 Sheets 연동 코드가 있으나 실제 활성화 여부는 확인 전입니다.

이 이름만으로 법적 수탁자·재수탁자 목록, 제3자 제공 관계, 실제 저장 국가나 보유 기간이 확정되지는 않습니다. 각 계약 주체·처리 업무·재수탁·접근 범위·보호 조치와 실제 계정 설정을 대조해야 합니다. 사용하지 않는 공급자를 임의로 추가하지 않았습니다.

국외 이전이 있다면 이전 항목, 국가, 시기·방법, 받는 자와 연락처, 목적·기간, 적용 근거 및 필요한 고지·권리 절차를 확정합니다. 모든 국외 처리가 같은 근거나 같은 동의 방식으로 허용된다고 단정하지 않습니다.

현재 미확정: 서비스별 실제 수탁·재수탁 계약, 제3자 제공 여부, 국외 처리 국가·방법·시점, 적용 근거와 보관 설정. 따라서 이 초안은 위탁이나 국외 이전이 없다고 선언하지 않습니다.

6. 분석·쿠키·접속 기록

이번 검토 버전은 기존 운영 도메인의 분석 구성을 보존하고, 추가 퍼널 이벤트는 기본 꺼짐 상태로 둡니다. 검토 미리보기와 자가진단·미팅 준비에는 분석 전송을 추가하지 않습니다. 공개 이벤트에 상호·전화번호·진단 답변·내부 고객 ID를 넣지 않습니다.

그렇다고 웹사이트가 어떠한 개인정보도 처리하지 않는다는 의미는 아닙니다. 호스팅·인증·분석 공급자가 처리하는 접속 기록, 쿠키와 온라인 식별자 등은 실제 서비스 설정과 계약에서 별도로 확인해야 합니다.

브라우저 설정에서 쿠키를 제한하거나 삭제할 수 있으나, 어떤 쿠키가 사용되고 설정 변경이 로그인·서비스에 어떤 영향을 주는지에 대한 구체적 안내는 실제 쿠키 조사 후 확정합니다. 이 문서에서 쿠키 선택이나 동의를 받은 것으로 처리하지 않습니다.

7. 권리 요청과 문의

열람·정정·삭제·처리정지·동의 철회 등에 관한 접수 창구, 본인 확인, 처리 절차와 제한 사유 안내는 개인정보 보호책임자 또는 담당 부서를 지정한 뒤 확정합니다.

현재 확인 가능한 경로는 footer의 기존 공개 문의 연락처입니다. 이 연락처가 전담 개인정보 권리 요청 창구로 지정되어 운영 중인지까지 확인한 것은 아닙니다. 최종 방침에는 담당 부서와 정확한 연락 방법을 명시해야 합니다.

문의할 때 비밀번호·인증 코드·주민등록번호·다른 고객의 예약명단을 보내지 마세요. 필요한 본인 확인 범위는 담당자가 별도로 안내해야 합니다.

일반적인 개인정보 권리·구제 절차는 개인정보 포털 ↗에서 확인할 수 있습니다.

8. 보호 조치와 입력 안내

검토한 FLOW 소스에는 인증 확인, 고객 연결 권한과 직원 권한의 분리, 공유된 업무의 제한적 조회, 공개 승인 상태에 따른 응답 구분이 있습니다. 홈페이지는 보호 API를 익명 상담 접수 창구로 바꾸지 않습니다.

접근 권한 관리, 암호화, 접속기록 보관, 내부 관리계획, 수탁자 감독, 사고 대응 등 실제 관리·기술·물리 조치의 운영 증거는 별도로 확인해야 합니다. 코드 테스트만으로 모든 보호 조치가 완료됐다고 주장하지 않습니다.

작업 의뢰나 상담의 자유기재에는 업무에 필요한 최소 내용만 남겨 주세요. 다른 사람의 연락처·예약명단·결제정보·민감한 내용을 공유해야 할 상황이면, 전달 근거와 안전한 경로부터 담당자와 확인해야 합니다.

9. 변경·시행과 다른 문서

이 초안의 검토 기준일은 2026년 10월 19일이며 시행일은 정하지 않았습니다. 확인 결과와 책임자 승인 후 확정 버전, 적용 범위, 시행일, 변경 내용을 안내합니다. 이 페이지는 로그인 없이 읽을 수 있도록 준비했습니다.

개인정보처리방침은 서비스 이용약관·작업 범위·계약·해지·환불 조건을 대신하지 않습니다. 서비스 조건은 진행 방식과 계약 조건 안내에서 확인하고, 실제 제안·계약에서 합의합니다.
