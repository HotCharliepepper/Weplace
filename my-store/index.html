A SIMPLE START

처음 한 번, 매장을 연결해 주세요.

01 / ACCOUNT

내 계정으로 로그인

사용할 이메일로 가입하고 이름을 설정합니다. 기존 계정이 있다면 그대로 로그인하세요.

02 / CONNECT

담당자에게 연결 코드 전달

로그인 후 ‘계정 연결 코드 만들기’를 누릅니다. 담당자가 대표님과 계약 매장을 확인해 연결합니다.

03 / CONTINUE

공유된 작업부터 확인

연결이 완료되면 최신 내용을 불러옵니다. 진행 상태를 확인하거나 필요한 일을 새로 요청해 보세요.

가입만으로 거래처 정보가 열리지는 않습니다. 담당자가 연결한 매장의 고객 공유용 작업과 의뢰만 확인할 수 있습니다.

이럴 때, 이렇게 사용하세요.

새 메뉴나 사진을 반영하고 싶어요.

로그인 후 ‘새 작업 의뢰’에 바꾸고 싶은 내용과 희망일을 적어 주세요. 자료 전달이 필요하다면 의뢰에 적고 담당자와 전달 방법을 정합니다. 담당자가 범위와 일정을 답변드립니다.

가입했는데 우리 매장이 안 보여요.

계정 연결 코드를 담당자에게 전달했는지 확인해 주세요. 코드는 24시간 동안 유효합니다. 연결 승인 후 ‘연결 상태 확인’을 누르면 됩니다. 직원 팀에 가입하실 필요는 없습니다.

예약 확정이나 비용 결제도 여기서 되나요?

현재는 작업 보고와 의뢰 접수, 담당자 답변을 확인하는 공간입니다. 입력한 희망일은 확정 일정이 아니며, 작업 범위·금액·일정은 담당자와 별도로 합의합니다.

아직 위플레이스 고객이 아니에요.

무료 매장 진단으로 현재 화면을 살펴보거나 카카오톡 상담으로 필요한 일을 이야기해 주세요.

매장을 함께 바꾸는 대화를 시작하세요.

진행한 일은 기록으로, 다음에 할 일은 요청으로.
