A SIMPLE START

처음 한 번, 내 계정과 매장을 연결합니다.

01 / ACCOUNT

내 계정으로 로그인

내 매장 로그인에서 안내에 따라 가입·이메일 확인을 마칩니다. 기존 계정이 있다면 같은 계정으로 로그인해 주세요.

02 / CONNECT

연결 코드를 담당자에게 전달

‘계정 연결 코드 만들기’를 누르고 위플레이스 담당자에게 전달합니다. 담당자가 기존 연락처로 대표님과 계약 매장을 확인한 뒤 연결합니다.

03 / CONTINUE

공유된 작업 확인

담당자의 연결 승인 후 ‘연결 상태 확인’을 누릅니다. 매장이 열리면 공유된 작업을 확인하거나 ‘새 작업 의뢰’를 남길 수 있습니다.

가입만으로 매장 정보가 열리지는 않습니다. 연결 코드는 24시간 동안 유효하며, 새 코드를 만들면 이전 코드는 만료됩니다. 대표님은 직원 팀에 가입하실 필요가 없습니다.

WHEN SOMETHING STOPS

연결이 안 되거나, 궁금한 점이 있나요?

로그인했는데 우리 매장이 안 보여요.

로그인한 계정이 담당자에게 전달한 연결 코드의 계정인지 확인해 주세요. 아직 연결 승인을 받지 않았다면 코드를 담당자에게 전달합니다. 승인 후 ‘연결 상태 확인’을 누르면 됩니다. 코드가 만료되었다면 새 코드를 만들어 전달해 주세요.

전에 보이던 매장이 사라졌어요.

먼저 기존에 사용하던 계정으로 로그인했는지 확인해 주세요. 같은 계정에서도 보이지 않으면 담당자에게 매장 연결 상태를 확인해 달라고 요청합니다. 새로운 직원 팀에 가입하거나 다른 사람의 계정을 사용할 필요는 없습니다.

로그인이 풀렸거나 화면을 불러오지 못했어요.

로그인 안내가 나오면 사용하던 계정으로 다시 로그인합니다. 연결 오류만 표시된다면 인터넷 연결을 확인한 뒤 ‘다시 확인’ 또는 ‘최신 내용 확인’을 눌러 주세요. 입력하던 작업 내용은 다시 시도하기 전에 별도로 보관해 두세요. 계속 막히면 오류 문구와 발생 시점을 담당자에게 알려 주세요.

매장은 연결됐는데 작업 기록이 없어요.

담당자가 고객에게 공유하도록 설정한 기록부터 표시됩니다. 연결 직후 아직 기록이 없을 수 있습니다. 확인하려는 작업을 담당자에게 알려주시거나, 새로 필요한 일이라면 ‘새 작업 의뢰’를 이용해 주세요.

메뉴나 사진을 바꾸고 싶어요.

‘새 작업 의뢰’에 바꾸고 싶은 내용과 희망일을 적어 주세요. 자료가 있다면 어떤 자료인지 설명하고 담당자와 전달 방법을 정합니다. 요청한 범위와 일정은 담당자와 협의해 확정합니다.

상담 기록이 자동으로 계약이나 작업이 되나요?

자가진단과 상담은 필요한 일을 정리하는 단계입니다. 미팅에서 범위를 확인하고, 제안·계약 내용을 합의한 다음 담당자가 작업과 일정을 준비합니다. 홈페이지의 체험 결과만으로 계약이나 작업이 자동 생성되지는 않습니다.

예약 확정이나 비용 결제도 여기서 되나요?

내 매장 관리는 공유된 작업과 의뢰를 확인하는 공간입니다. 입력한 희망일은 확정 일정이 아닙니다. 작업 범위·금액·일정은 담당자와 별도로 합의하며, 이 안내 페이지에는 결제 기능이 없습니다.

아직 위플레이스 고객이 아니에요.

손님의 시선으로 화면을 체험한 뒤 우리 매장 자가진단으로 필요한 안내를 정리해 보세요. 카카오톡 상담 ↗에서 그 내용을 직접 전하며 시작할 수 있습니다.

우리 매장의 다음 일을 이어가세요.

공유된 기록을 확인하고, 필요한 질문을 남깁니다.
