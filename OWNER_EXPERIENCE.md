# Weplace owner experience · 2026-10-14

The public homepage, active industry pages, Field Notes and FLOW use the existing black/blue Weplace symbol (`apple-touch-icon.png`) and the `We,place.` wordmark. Keep the symbol original. Public content uses paper, deep green and generous spacing; product descriptors remain separate from the brand.

## Entry points

- `/check/`: six-question self-report. Industry is required. No answer is selected by default. Unknown is an explicit answer, not a zero score.
- `/my-store/`: client portal purpose, account-linking steps, practical FAQ and login entry.
- `/client`: existing redirect to the authenticated FLOW portal. `/team` remains the employee entry.

## Diagnostic rules

Answers are processed in memory. No login, API request, local storage, lead record or analytics payload is generated by the quiz. A reload clears answers. A user can download a plain text result or explicitly copy it and paste into KakaoTalk. Copy failures select the text for manual copying. No inquiry is automatically sent.

Priority: first `no`, otherwise first `unknown`, otherwise first `part`, otherwise maintenance guidance. Ties use question order. A strength requires a `yes`. Six unknowns do not produce a fabricated strength. Output is a response-based recommendation, never an audited rating, personality diagnosis, measured conversion, sales prediction or package-fit percentage.

## Validation

The static diagnostic was exercised with JSDOM: unselected initial state, missing industry/question, six unknown answers, all yes, reservation weakness, answer editing, six-answer evidence list and text export. No persistence occurred.

Field Notes assets are built from the FLOW repository with `npx vite build --config vite.portal.config.ts`. Preserve existing assets and redirects when publishing this patch. The staged folder used during development is not a complete public repository.
