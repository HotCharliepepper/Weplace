## 3. 고객 문의 응대 SOP — 한 번에 한 질문

### 상태 정의
1. **발송 승인 전**: 명단 출처·수신 동의·중복·광고 표시 확인.
2. **메시지 발송**: 발송과 노출은 별개. 관리자센터의 실제 발송 성공 확인.
3. **랜딩 체험**: 선택/복사는 클라이언트에만 있으며 서버 저장·전송되지 않음. UTM만으로 클릭 수를 측정했다고 주장하지 않음.
4. **인입**: 고객이 카카오톡으로 직접 메시지 전송했을 때만 문의 접수.
5. **담당 지정**: 중복 인입·기존 진행 사항을 담당자가 확인. 상담/작업 동의 범위 구분.
6. **진단 준비**: 매장 이름/지역/공개 링크 등의 최소 자료를 요청(불필요한 민감정보 금지).
7. **범위 안내**: 가능한 확인 범위와 방법/비용/일정 제안. 미확정 무료 혜택이나 매출 보장 언급 금지.
8. **후속 상태**: 적합/대기/미팅/제안/계약/수금 각각 별도 기록. 고객의 중단 선택 존중.

### 상담 답장 템플릿

**A. 처음 상담하는 대표님**
안녕하세요, Weplace입니다. 비교 화면에서 [사진/길/예약]을 선택하셨군요. 그 부분을 먼저 확인하고 싶으셨던 이유가 있으실까요? 매장명과 지역 또는 공개 페이지 링크 하나만 알려주시면, 담당자가 어떤 범위로 확인할 수 있을지부터 안내드리겠습니다. 실제 진단 제공 방식·비용·일정은 확인 후 말씀드리겠습니다.

**B. 이전 상담 또는 협업 이력이 있는 대표님**
다시 찾아주셔서 감사합니다. 먼저 기존에 함께 살펴봤던 범위를 확인한 다음, 현재 [사진/길/예약]에서 무엇이 가장 달라졌는지 이어서 보겠습니다. 지금 가장 불편한 화면 또는 확인하고 싶은 항목 하나를 알려주시겠어요? 현재 진행 중인 작업과 중복되지 않게 안내드리겠습니다.

**C. 가격/혜택 문의**
이번 11월에 바로 열어보실 수 있는 건 가입 없는 가상 화면 비교 체험입니다. 실제 매장의 진단서 제공이나 작업 비용은 현재 캠페인에서 확정해 안내하고 있지 않습니다. 어느 화면이 가장 신경 쓰이시는지 한 가지만 알려주시면, 가능한 범위부터 확인해 안내드리겠습니다.

**D. '광고하지 말라더니?'라는 반응**
광고를 전부 멈추라는 뜻은 아닙니다. 이미 광고를 해보신 대표님이라면 광고를 클릭한 이후의 사진·안내·예약 흐름도 확인할 필요가 있다는 의미였습니다. 표현이 혼란스러우셨다면 정확히 설명드리겠습니다.

**E. 수치·실적/고객 사례 요청**
현재 캠페인에 나오는 전후 화면은 실제 고객 매출 성과가 아닌 가상 예시입니다. 공개 범위와 근거가 확인된 사례만 별도로 안내드릴 수 있으며, 검증되지 않은 성과를 약속하지 않습니다.

**F. 지금 상담하지 않겠다는 반응**
네, 필요할 때 다시 비교 화면을 열어보셔도 됩니다. 오늘은 추가 진행을 권하지 않겠습니다. 원하시는 문의가 생기면 언제든 채널로 말씀해 주세요.

### 운영 담당자용 최소 확인표 (고객에게 한꺼번에 보내지 않음)
- 문의 경로: 채널 친구 / 과거 광고수신 동의 연락처 / 직접 인입 / 확인 불가
- 기존 관계: 이전 상담 / 계약·진행 / 진행 완료 / 이력 미확인 (당사 실제 원본과 대조)
- 고객이 선택한 주제: 사진 / 길 / 예약 / 기타
- 현재 가장 불편한 점: 고객 표현 그대로 한 문장
- 공개 확인 자료: 매장명·지역·링크 등 필요한 최소 정보
- 다음 행동: 담당자 확인 / 가능 범위 설명 / 미팅 조율 / 보류·거절
- 비용/수금/약속: 합의된 경우에만 해당 원본 위치에 별도 기록

고객의 개인정보는 공개 GitHub/캠페인 HTML에 저장하지 않는다. 회사에서 승인한 CRM 또는 접근권한이 있는 내부 기록처를 사용한다.

## 4. 내부 응대 목표 (확정 약속이 아닌 제안)
- 첫 응답은 담당 업무 시간 내 가능한 빠르게; 내부 목표 **1시간 이내**를 제안하되 담당 인력의 실제 근무/응대 가능 여부 확인 전 고객에게 SLA 약속 금지.
- 첫 답변은 질문 **하나**. 받은 답변에 따라 공개 링크/정보를 요청. 한 번에 설문 여러 개 발송 금지.
- 상태가 불명확한 고객에게 기존 거래/협업을 사실처럼 단정하지 않는다.
- 마지막 답변의 선택지는 “확인 후 안내/다음 상담/여기서 마무리”. 불필요한 압박·재접촉 금지.

## 5. 내부 테스트 단계와 출시 보류 조건

**오후 5시 이후 테스트 예정**은 내부 검토를 위한 수동 행동 계획이지 자동 예약 발송이 아님.
- iPhone Safari/Android Chrome/Kakao 인앱: 광고 클릭→후킹→반전→FAST→선택→개별 작업→FLOW 새 창→복귀→상담 분기→복사→카카오톡 실제 수신(내부 테스트) 확인
- 정식 도메인·회사/개인정보 고지 검수 전 외부 대량 발송 금지.
- 카카오 채널 친구와 동의가 확인된 기존 연락처를 분리; 수신거부·광고성 표기 및 중복 발송 검토.
- 실제 자료 사용권/실적·혜택 범위·비용·일정·문의 담당자 확인되지 않으면 광고 외부 발송 보류.
- 전화번호 기반 메시지 그룹은 동의 및 관리 권한 확인 전 업로드하지 않는다.
- 실제 열람/클릭/문의 성과는 카카오 발송 리포트 등 확인된 자료로만 기록. 랜딩의 선택 데이터는 추적하지 않음.
