**범위:** 캠페인용 진입 문장 + 타이포 FAST 히어로 + 기존 3선택/전후 비교 + 카카오 문의문.

## 왜 이 문장을 택했는가

대상은 여러 차례 Weplace 홍보를 접한 채널 친구와 기존 상담/거래 연락처다. 모두를 새 광고가 필요한 초보 고객으로 가정하지 않는다.

- 공감: **광고를 해보셨다면, 그다음 화면이 궁금하실 겁니다.**
- 관찰: 사진은 올렸고 광고도 해봤지만, 고객의 다음 질문이 남아 있을 수 있다.
- 체험: 가상 매장 세 가지 화면 중 한 가지 선택, 정리 전후 비교.
- 다음 행동: 확인한 주제를 포함한 일반 문의문 복사 후 사용자가 카카오톡에서 직접 전송.

11월/블랙프라이데이의 온기는 금액 할인·긴급 판매·무료 진단을 뜻하지 않는다. **11월의 작은 온기**는 가입·연락처 없이 이용할 수 있는 선택형 공개 체험이라는 실재하는 제공물에만 적용했다. 결과물 제작, 무료 진단, 우선 처리, 납기는 실제 운영 담당자가 확정할 때까지 공개하지 않는다.

## 기술

- 원본 A의 `data-focus`/ `data-mode`, `#prepared-message`, `#copy-message`, 채널 URL 유지.
- 단일 HTML, 화면/애니메이션/CSS 전부 자체 포함. R3 미승인 수치/고객 사진/기존 로그인·FLOW·DB 코드 포함하지 않음.
- FAST는 실제 DOM 텍스트, 약 560ms 유한 CSS 애니메이션. 가속 → 얕은 왼쪽 잔상 → 정착. 사용자 요청으로 재생 가능. 무음 기본, 반복 루프 없음.
- `prefers-reduced-motion`, Save Data 및 페이지 비가시 상태에서는 정적/중지.
- `noindex,nofollow`는 검색 방지 힌트이지 비공개 접근 제한이 아님.
- 가입/매장명 수집, GA4 등 신규 추적, 자동 카카오 발송, CRM write, 결제 없음.

## 광고 메시지 작업안 — 실제 발송 전 관리자 검수

이 문구는 승인된 최종 광고가 아니며, 법정 표시와 카카오 채널 발송 방식은 실제 관리 화면에서 확정한다.

### 채널 친구(광고 경험 여부가 모두 다름)

(광고) Weplace

광고를 해보셨다면, 그다음 화면이 더 궁금하실 겁니다.

대표 사진은 충분할까요?
처음 오는 손님은 길을 찾기 쉬울까요?
예약 전 한 번 더 묻는 질문은 없을까요?

이번 11월에는 말 대신 직접 비교해 볼 수 있는 세 가지 가상 화면을 준비했습니다.

[정식 캠페인 URL — 승인 후 입력]

실제 매장 진단의 범위·비용·일정은 별도로 안내합니다.
[실제 관리자센터에서 제공하는 수신거부 표기 확인]

### 이전에 위플레이스와 대화 또는 협업한 동의 고객

(광고) Weplace

지난번에 광고나 매장 안내에 관해 이야기를 나눈 뒤, 시간이 조금 흘렀습니다.

이미 정리한 화면이라도 처음 오는 손님의 질문은 달라질 수 있습니다. 사진·찾아오는 길·예약 중, 어디서 다시 확인이 필요할까요?

11월에는 이 세 화면의 배열을 직접 바꿔볼 수 있도록 작은 비교 체험을 열었습니다.

[정식 캠페인 URL — 승인 후 입력]

이 문구는 기존 협업 성과나 개인별 관계를 주장하는 개인화 메시지가 아닙니다. 상대의 실제 관계가 확인된 동의 그룹에서만 사용합니다.

## 발송 게이트 (모두 충족하기 전 외부 광고 발송 보류)

1. 운영 담당자가 공식 캠페인 URL과 회사 정보·개인정보 안내의 정확성과 공개 가능 여부 확인.
2. 공개 이벤트/제공물 실제 범위: 실매장 진단 무료/유료, 전달물, 소요 기간, 신청 자격, 혜택 예산/수량을 실제 운영 능력 기준으로 확정.
3. 수신동의 목록 확인: 채널 친구, 기존 연락처 분리; 발송 목적에 적합한 동의·수신거부 반영; 교집합 중복 발송 방지.
4. 광고 표시 및 수신거부 UI를 카카오 채널 관리자센터에서 실제로 대조.
5. iPhone Safari/Android/Kakao 인앱에서 페이지·전후 체험·문의문 복사·카카오톡 이동을 실기기로 확인.
6. 문의 인입 담당자와 답변 가능한 범위 및 당일 운영 시간을 정하고, 실제 연락 시험은 내부 승인 대상만 사용.
7. 전환 검수는 단순 클릭, 상담 문의, 실제 계약/수금을 별도 상태로 기록. 첫 랜딩은 별도 이벤트 추적을 사용하지 않는다.

## 범위 제외

- 메인 홈페이지 `/` 교체, CRM/실DB, FLOW, 인증, 결제, 공식 출시, 외부 대량 메시지 발송.
- 확인되지 않은 매출 향상 효과, ‘오늘만’, ‘한정’ 수량, 할인 금액, 무료 1장 진단.
- PR #43의 복합 통합 경험이나 실고객 성과 자료.
