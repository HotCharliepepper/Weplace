## 발견·수정한 결함

자동 회귀 검수 중 공개 API의 기존 기록이 만료되면서 해당 컨트롤의 키보드 초점이 사라지는 경우를 발견했다. 같은 업종의 summary로 초점을 복귀하도록 수정했고 정상 갱신·만료·조회 실패 검사를 통과했다. FLOW 원본이나 승인 조건은 바꾸지 않았다.

브라우저 검수에서 정확한 accessible name에 장식 화살표를 포함한 선택자는 매칭되지 않았다. 실제 DOM의 링크 경로·기존 데이터 속성으로 선택해 검수를 이어갔다. 서비스의 링크 오류가 아니다. 전체 페이지 캡처가 한 번 시간 초과되어 기본 viewport 캡처로 기록했다.
