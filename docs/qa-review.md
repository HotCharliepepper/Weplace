# WEPLACE 홈페이지·FLOW 통합 검수

기준일: 2026-10-19 KST. 이 문서는 로컬 소스·DOM 동작·테스트 결과를 구분하여 기록한다. 운영 배포 승인 문서가 아니다.

최종 실행: 홈페이지 저장소 `npm test` **37개 통과 / 실패 0 / 생략 0**. 구성은 journey 17개, privacy 6개, public-integration 14개다. 로컬 링크·자산 검사와 배포용 build 역시 완료했으며, 최종 실행 상세는 통합 인벤토리와 PR 기록을 함께 확인한다.

## 검수 방식과 한계

- `tests/journey.test.cjs`: Node test runner + JSDOM으로 질문·결과·업종 전달·미팅 준비·명시적 내보내기·HTML 메타·인라인 스크립트 문법을 검사한다.
- `tests/privacy.test.cjs`: fetch, XHR, beacon, storage, cookie, gtag, console을 계측한 JSDOM에서 진단·미팅의 입력 및 선택 동작이 전송·저장 호출을 만들지 않는지 검사한다. 외부 URL은 호출하지 않는다.
- `scripts/check-links.py`: 로컬 경로, 앵커, CSS 자산, sitemap, `_redirects`를 검사한다. 외부 서비스의 HTTP 성공을 대신 증명하지 않는다.
- JSDOM은 CSS 레이아웃·스크린리더·실제 모바일 브라우저를 검증하지 않는다. 스크린샷, 360/390/430/768/1024/1440px 렌더링, 모바일 터치, Lighthouse, 느린 네트워크 실측은 **NEED VERIFY**다. 검수용 화면 크기 조절 페이지가 있어도 실측 완료로 계산하지 않는다.

재현: 의존성 설치 후 `npm test`. 환경에 이미 설치된 jsdom을 사용할 경우 `NODE_PATH=<node_modules 경로> npm test`. 테스트는 저장소에 특정 작업 환경의 절대 경로를 요구하지 않는다.

## FLOW 확인 결과의 범위

FLOW 조사 담당자의 로그와 소스를 교차 검토했다. 로컬 원본 후보의 Git tree 226개 파일과 복구 ZIP 226개 파일이 바이트 해시로 일치했고, 운영 공개 index 및 8개 JS/CSS는 새 원본 빌드와 일치한다. 이것이 운영 서버 함수 11개의 원본 바이트까지 검증했다는 뜻은 아니다.

- 기존 FLOW 테스트: **145개 통과**, typecheck/build 통과. 상세는 `flow-source-audit.md`와 `flow-source-manifest.json` 참조.
- 테스트 전용 인입 어댑터: **8개 통과**. 닫힌 가상 fixture만 허용하고 실제 연락처·추가 필드·미동의·중복 ID의 다른 본문을 거부한다. transport/live 모드가 없고 기존 앱/Function에 import되지 않는다.
- 어댑터는 기존 잠재고객 스키마와 `신규` 단계를 이용해 검토 자료만 만든다. 이메일/동의를 기존 전화 필드에 끼워 넣지 않으며 `acceptedByCrm`, `persisted`, `sent`는 모두 false다.
- 기존 226개 운영 후보 파일은 변경하지 않았다. 기존 인증·역할·CRM·API·공개 승인 기능을 이 작업으로 변경하지 않는다.
- 운영 익명 GET 확인에서 session/prospects/client-portal은 401, 공개 API 2개는 200·빈 결과로 보고되었다. **인증된 고객/직원 세션, 다른 고객 접근 차단, 세션 만료·로그아웃·복귀 동작은 미검증**이다.

## 운영 승인 전 남은 확인

1. PR Deploy Preview를 실제 브라우저에서 지정 폭·키보드·터치·축소 모션·느린 네트워크로 확인한다. 실제 스크린샷과 측정 가능한 성능값을 남긴다.
2. 테스트 계정에서 FLOW 직원/고객별 권한·프로젝트 연결·세션 만료·로그아웃을 확인한다. 운영 고객 데이터로 임의 테스트하지 않는다.
3. 공개 집계/저널의 운영 승인·만료/오류 UI는 가상 응답 테스트와 실제 계약·권한 확인을 구분한다.
4. 자동 인입은 동의 문안·보관/삭제·중복/스팸·권한·담당자·스키마·배포 경로를 승인한 뒤 별도 구현한다. 이번 어댑터는 전송 또는 CRM 저장 기능이 아니다.
5. 공개 가격·범위·부가세·착수·해지/환불 및 결제 주체가 승인되기 전 계약/결제를 활성화하지 않는다.
6. 신규 분석 이벤트의 활성화와 운영 main 병합·배포는 사용자 최종 승인 대상이다.
