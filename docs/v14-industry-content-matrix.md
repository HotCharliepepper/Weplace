### API 재조회 시 상태

- 기존 바깥 폴더는 `data-industry`, 중첩 보조 폴더는 고유 `data-disclosure`를 기준으로 펼침 상태를 복원한다.
- 승인된 정보가 계속 유효하면 중첩 summary의 키보드 초점도 같은 위치로 복원한다.
- 공개 기한 만료나 조회 실패로 현재 초점이 있던 기록이 사라지면 해당 업종의 바깥 summary로 초점을 돌린다. 만료 자료를 남겨서 초점을 유지하지 않는다.
- 사용자가 직접 연 바깥 폴더에만 기존 v1.3 모션을 적용한다. 갱신 복원에는 진입 모션을 재생하지 않는다.
- 새 분석 이벤트·저장·네트워크 요청은 추가하지 않았다. 기존 익명 공개 GET과 허용된 체험 이벤트만 유지한다.
