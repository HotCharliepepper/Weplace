## 2. 캠페인 장면 순서

| 장면 | 대표님이 마주하는 문장·행동 | 목적 |
|---|---|---|
| 0 / Cold Open | '광고, 하지 마세요.' / '어차피 돈만 들지 않나요?' | 자극적인 광고 문장에 익숙한 사람도 멈춰보게 |
| 0 / Reversal | '광고를 멈추자는 뜻은 아닙니다. 손님이 광고 다음에 보는 그 화면부터 먼저 확인하자는 이야기입니다.' | Weplace가 광고 자체를 부정하지 않음을 같은 첫 장면에서 해소 |
| 1 / Warm R1 | '광고 이후, 손님이 머무는 화면을 다시 볼 차례입니다.' + '11월의 작은 온기' | 계절감과 고객 관심을 행동에 연결 |
| 2 / RESOLUTE IT FAST | 기존 약 560ms 유한 모션 / 기본 무음 | 속도감은 한 번. 과도한 강제 스크롤·대기 없음 |
| 3 / 직접 비교 | 사진 · 찾아오는 길 · 예약 / 정리 전후 가상 매장 | 구체적인 작은 발견 |
| 4 / 문의 | 선택 반영 문의문 → 복사 → 카카오톡 열기 | 대표님이 스스로 문의 여부 결정 |

의도된 감정은 **회의 → 짧은 긴장 → 반전 → 안심 → 직접 비교 → 선택**. 직접 매출 개선이나 실제 고객 성과를 보여주지 않으므로, 이를 결과 예측으로 단정하지 않는다.

## 3. 반전 카피 판단

'광고, 하지 마세요'는 **광고를 접해본 대표님이 품을 수 있는 의문**을 인용하는 표현이다. 그 즉시 '광고를 멈추자는 뜻은 아닙니다'를 보여 오해와 절망을 남기지 않도록 한다. 이 반전이 실제 고객의 감각에도 통하는지는 테스트 대상의 피드백으로 판단한다.

**현재는 사용자 승인 없이 발송이나 운영 배포를 진행하지 않는다.** 17시 이후 실행 주체가 이 문서를 열어 아래 순서로 검수.

2. 390px 모바일: 반전이 첫 장면에서 충분히 보이는지, **'그래서, 무엇부터 바꿀까요?'** 버튼으로 R1 온기가 이어지는지 확인.
3. FAST: 한 번만 가속·왼쪽 잔상·정착 후 정지하는지, 다시 보기, 줄어든 움직임을 확인. 소리는 기본 무음.
4. 각각 대표 사진·길·예약 누르기 → 정리한 화면 보기 → 질문과 문의문이 해당 선택으로 바뀌는지 확인.
5. **내부 테스트 계정만** 문의문 복사 → 카카오톡 채널 열기 → 실제 채널에 수신되는지 담당자와 확인. 메시지 자동 전송 기능은 없다.
6. 채널 친구 대상과 기존 연락처 대상 명단을 분리하고 수신 동의, 광고 표시, 수신 거부, 중복 발송 여부 확인. 수신 동의 없는 목록은 제외.
7. 테스트 피드백 항목: ① 3초 첫인상(도발·거부감 여부) ② 반전 이해 여부 ③ FAST 속도 체감 ④ 가상 예시임을 이해했는지 ⑤ 문의로 넘어갈 의향.
8. 합격 기준: 공개 URL의 안정적 표시, 모바일 주요 클릭 모두 정상, 문의 진입 문제 없음, 검토 문구의 오해 위험 없음.
