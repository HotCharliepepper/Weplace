# Weplace Massage & Esthetic — Visual Refinement v2

## 0. 작업 방식

이 문서는 마사지·에스테틱 페이지와 Weplace 메인페이지의 2차 세부조정 기준이다.

기본 순서는 다음과 같다.

1. 구조·문장 프로토타입
2. 실제 이미지 배치
3. Figma에서 시각화
4. 시각화된 화면을 보고 감정·가독성·전환 흐름 조정
5. 최종 HTML 프로토타입
6. 정본 반영

가격은 이번 단계에서 넣지 않는다. 먼저 대표가 자기 매장을 새롭게 보게 만드는 구조가 실제 화면에서도 작동하는지 확인한다.

---

## 1. 이번 라운드의 핵심 목표

마사지·에스테틱 페이지를 본 대표가 다음 순서로 느끼게 한다.

1. "우리 업종 얘기네."
2. "우리도 사진은 괜찮은데, 무슨 관리를 하는지는 바로 안 보일 수도 있겠네."
3. "손님은 가격·시간·예약·입구까지 이렇게 확인하는구나."
4. "Google부터 정리해보는 건 부담스럽지 않겠네."
5. "그 다음 홈페이지·FAQ·AI 검색 정보까지 이어질 수 있겠구나."

Weplace가 문제를 선언하는 것이 아니라, 비교와 자기 선택을 통해 대표가 먼저 발견하게 한다.

---

## 2. 페이지 톤

### 유지
- 따뜻한 아이보리
- 짙은 우드·브라운
- 절제된 골드
- 실제 한국 로컬 매장 같은 현실감
- 차분한 운영 정돈감
- 여성 대표가 보았을 때도 부담 없는 세심함과 신뢰

### 피하기
- 과한 핑크·화이트 뷰티 광고 톤
- 호텔 스파처럼 비현실적인 럭셔리
- 모델 중심 이미지
- 의료 시술처럼 보이는 장면
- 빨간 경고·등급·점수 중심 진단
- "문제", "잘못", "손해"를 전면에 둔 공격적 표현

### 문장 원칙
- "안 되어 있습니다"보다 "조금 아깝게 보입니다"
- "문제가 있습니다"보다 "한 번 더 확인해야 하는 자리가 있습니다"
- 기존 공간·관리·국내 고객 기반을 먼저 인정한다
- 부족함보다 이미 가진 장점이 화면에서 덜 보이는 상황을 설명한다

## 3. 핵심 이미지 6장

현재 생성 이미지 1~8 중 1차 실사용 기준은 다음과 같다.

### Image 3 — Hero / Category Clarity
역할: 메인 대표 이미지 1순위.

보여야 하는 것:
- 마사지·에스테틱 업종이 즉시 읽힘
- 리셉션·가격·관리 공간이 한 프레임에서 연결됨
- "실제 운영되는 곳"이라는 감각

주의:
- Hero 카피가 이미지 안의 안내문과 경쟁하지 않도록 크롭 시 텍스트 밀도를 조절한다.

### Image 2 — Vague but Attractive
역할: "예쁜데 업종이 늦게 읽히는 화면"의 비교 예시.

핵심:
- 나쁜 디자인 사례로 취급하지 않는다.
- 분위기는 좋은데 마사지·에스테틱·페이셜 중 무엇을 하는 곳인지 첫눈에 늦게 읽힌다는 관찰만 한다.

### Image 4 — Service Detail
역할: 관리 공간·준비 상태·서비스 이해.

핵심:
- 모델 없이도 실제 관리가 이루어질 공간이라는 점이 읽힘
- 타월·제품·베드의 정돈이 안심 근거 역할을 함

### Image 6 — Consultation / Reassurance
역할: 첫 방문 안심, 상담·응대, 해윤제 레퍼런스.

핵심:
- 상담카드·차·직원의 존재로 운영 온도가 보임
- "맡겨도 괜찮겠다"는 감정 형성

### Image 7 — Foreign Visitor Accessibility
역할: 외국인 고객 정보 접근성, 난다아로마 레퍼런스.

핵심:
- 서비스·예약·위치·이용 안내가 한 프레임에서 읽힘
- 단순 번역이 아니라 이용 흐름이 정리된 상태를 보여줌

### Image 8 — First Visit / Wayfinding
역할: 첫 방문 동선·안내·도착 안심.

핵심:
- 처음 오는 고객이 무엇을 하고 어디로 가는지 자연스럽게 상상할 수 있음
- 해윤제의 "어떤 곳 → 나에게 맞는지 → 믿고 가도 되는지 → 무엇을 받을지 → 어떻게 예약할지" 흐름과 연결

## 6. 메인페이지 배치 기준

메인페이지에서는 마사지·에스테틱 업종을 과하게 판매하지 않는다.

권장 위치:

Hero
→ 고객 판단 에너지
→ 손님 눈으로 보기
→ Massage & Esthetic Field Focus
→ AI/첫 표면
→ 진단서
→ 업종별
→ CTA

Field Focus에는 상세페이지 전체를 요약하지 않는다.

딱 다음까지만 보여준다.
- 좋은 공간인데 업종이 늦게 읽히는 예
- 한눈에 읽히는 예
- 난다아로마 = 정보 접근성
- 해윤제 = 첫 방문 안심
- 상세페이지 CTA

## 7. Figma 세부 기준

### 프레임
Desktop 우선 1440px.
Mobile 보조 390px.

### 본문 폭
메인 텍스트는 620~720px 내외.
이미지 비교 구간은 필요 시 960~1120px까지 확장.

### 이미지 크롭
- Hero: 16:10 또는 4:3 계열, 업종 표식과 룸이 동시에 보이게
- 비교: 두 이미지 동일 비율
- Service: 4:5 또는 3:4
- Consultation: 4:5
- Foreign Visitor: 4:5 또는 3:4
- Arrival: 4:5 또는 3:4

### 이미지 라벨
작게 사용:
- FIRST LOOK
- SERVICE
- TRUST
- FOREIGN VISITOR
- ARRIVAL

라벨은 사진보다 튀지 않는다.

### 캡션
한 이미지당 관찰문 1줄 + 확인 포인트 2~3개.
긴 본문을 이미지 아래에 반복하지 않는다.

### 사진 비중
- 공간·리셉션 35~40%
- 관리실·준비 상태 25~30%
- 상담·안심 15~20%
- 외국인 안내·도착 15~20%

### 모션
모션은 정보 이해를 돕는 정도만.
- 비교 Before/After 부드러운 전환
- Section reveal
- CTA hover
- 모바일에서는 과한 패럴랙스 금지

## 8. Figma 시각화 후 반드시 판단할 4가지

### 1. 첫 3스크롤의 감정
질문:
- 마케팅 회사처럼 보이는가?
- 아니면 내 매장을 보게 만드는 페이지인가?
- 여성 대표가 읽을 때 방어가 올라가는 문장이나 시각 요소가 있는가?

### 2. 비교 화면의 현실감
질문:
- 교과서적 Before/After처럼 보이는가?
- 아니면 실제 자기 플레이스를 떠올릴 수 있는가?
- 나쁜 사례가 지나치게 못나 보여 방어가 생기지는 않는가?

### 3. 난다아로마·해윤제 증거화 수준
질문:
- 사례 자랑처럼 보이는가?
- 구조 레퍼런스로 읽히는가?
- 실제 화면 캡처를 추가할 필요가 생기는가?

### 4. 전체 시각 밀도
질문:
- 사진이 너무 많아 뷰티 브랜드 사이트처럼 변하지 않았는가?
- 텍스트가 너무 많아 진단서처럼 무거워지지 않았는가?
- Google 진입상품이 너무 빨리 판매처럼 느껴지지 않는가?

## 9. 다음 조정 방식

Figma와 최종배치 프로토타입을 본 뒤 아래 4개 중 하나로만 수정 사유를 분류한다.

- KEEP: 그대로 유지
- REDUCE: 설명·이미지·요소를 줄임
- MOVE: 순서·위치를 이동
- REBUILD: 섹션 자체를 다시 설계

시각화 이전에는 미세문구 수정에 과도하게 시간을 쓰지 않는다.
