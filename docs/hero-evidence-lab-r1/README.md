## 2. 4개 연도 매출 — 사용자 정정 반영

| 연도 | 4월(억원) | 5월 | 6월 | 5→6월 |
|---|---:|---:|---:|---:|
| 2023 | 1.70 | 1.79 | **1.60** | −10.61% |
| 2024 | 1.66 | 1.96 | 1.94 | −1.02% |
| 2025 | 1.91 | 2.02 | **1.70** | −15.84% |
| 2026 | 1.74 | 1.72 | 1.93 | **+12.21%** |

- 2023.06 1.60억, 2025.06 1.70억은 **사용자가 중복 연도 오기를 정정해 확정한 제공 수치**. POS 원장 감사·제3자 검증 완료를 뜻하지 않는다.
- 같은 기준의 네 연도라고 가정할 때, **제공한 4개 연도의 5→6월 중 2026년만 상승**이라는 비교는 성립한다.
- 더 큰 배경 요인, 계절성, 정책 변화, 메뉴 가격, 방문객 변화, 다른 광고 등이 구분되지 않으므로 **Weplace의 사진 교체 때문에 매출 상승했다고 단정하지 않는다.**
- 그래프는 **모든 연도 동일한 1.50억~2.10억 세로 범위**이며, 0 기준이 아닌 점을 표기한다. 클릭 가능 연도 버튼은 \`aria-pressed\` 상태로 표시되고 기본 강조는 2026년이다.
- 2024 등 다른 연도를 선택하면 **선들이 겹쳐 보이는 다중 선택** 방식. 네 해 모두 선택 버튼, 2026만 강조 버튼, 키보드 사용 가능. 스크린리더와 모바일 대응을 위해 동등한 수치 표도 제공.

## 3. 플레이스 유입 168%는 별도의 지표

- 제공된 스마트플레이스 월간 상세 유입 횟수: 2026.05 **877회** → 2026.08 **2,350회**, 차이 **+1,473회**, 증가율 \`(2350-877)/877×100≈168.0%\`.
- 유입 횟수는 실제 방문 고객의 실인원이나 클릭률(CTR), 매출, 문의 전환율이 아니다.
- 다른 업종의 평균 유입량으로 사용하지 않는다. 동일 지표/기간/노출원/원본 관리자 화면과 고객 공개 권한은 운영 전에 재확인.
- **플레이스 유입 지표는 웰니스 B**, 4개년 매출은 음식점 A의 기록으로, 서로 **다른 사례**다. 두 지표가 같은 매장에서 나온 것처럼 제목·사진·근거를 혼동시키지 말아야 한다.

## 4. 사진 순서 스토리

- \`차량이 보이는 외관 → 짧은 멈춤 → 베이징덕 대표메뉴\` 장면은 실제 루위 제공 사진을 사용한 **시각적 비교 사례**.
- 버튼으로 외관/메뉴를 직접 선택. 메뉴 선택 시 약 470ms 멈춤 후 전환; 움직임 줄이기·수동 OFF에서는 대기 없이 즉시 변경.
- 매출·유입 숫자와 사진 전환 사이의 인과관계를 시각적으로 연결하지 않는다. **실제 바뀐 것은 ‘먼저 보여주는 정보’임을 명시**한다.
- 별도 음성/음악을 자동재생하지 않으며, 기존 FAST 짧은 선택형 효과음만 보존한다.

## 6. 음악/사운드 선택 — 아직 별도 음원 미삽입

1. **권장:** 사이트의 10~25초 루프 또는 2~4초 짧은 전환 신호를 **새로 제작**. 무음 기본, 이용자가 명시적으로 사운드 ON을 눌렀을 때만 재생. 음량·재생 상태·일시정지/페이지 전환·모바일 데이터 절약·파일 용량을 QA한다.
2. **YouTube Music / YouTube:** 상업적으로 유통된 곡을 다운로드·오디오 분리·숨긴 배경 플레이어로 사용하는 방식은 피한다. YouTube 임베드 플레이어 자체는 허용된 조건에서 가능하지만, UI를 숨기거나 소리만 추출/변형하는 구조는 YouTube 정책에서 제한한다. 참고: https://developers.google.com/youtube/terms/developer-policies
3. **Suno:** 무료로 만든 곡은 상업적 이용 허락 대상이 아니며, 이후 결제해도 자동 소급되지 않는다. Pro/Premier 상태에서 만든 곡의 상업 이용 조건은 공식 안내를 다시 확인해 증빙한다. https://help.suno.com/en/articles/9601665
4. **Stable Audio:** 2026년 공식 제품 페이지는 무료 플랜 포함 상업 라이선스를 안내하지만 2023년 공개 약관에는 차이가 있다. **계정 생성 시 실제 적용 최신 약관·다운로드 시 사용권·모델·원본 샘플 사용 여부를 확인 후** 도입한다. https://stableaudio.com/
5. 음악이 없어도 FAST 장면이 온전히 읽혀야 한다. 운영용 새 오디오 파일·자동재생·외부 음악 서버는 이번 코드에 추가하지 않는다.
