## 변경한 네 부분
1. **02A 선명도**: 기존 외관 이미지의 \`scale(1.48)\` 및 모바일 \`scale(1.6)\` 오버라이드를 제거. 908×689 WebP 원본을 object-fit:cover, 자연스러운 crop으로 렌더링한다. 베이징덕은 기존 1254w/640w 후보 그대로 사용하며 이미지 자체를 AI 업스케일했다고 주장하지 않는다. 4개년 매출선은 원래 SVG 벡터이므로 원본 수치/선명도 보존. 모바일 650px 가로 스크롤은 축·숫자가 작아지는 것을 막는 의도적 선택.
2. **사진 비교 선택**: 외관 화면 위에 "사진은 보셨죠? 메뉴도 한번 볼까요? ↗" 독립 버튼과 옆 CTA "메뉴도 한번 볼까요? ↗" 제공. 버튼은 새로운 제출/추적이 아니고 기존 \`[data-photo-choice=after]\`를 클릭해 470ms 단일 멈춤 → 베이징덕 이미지를 보여준다. 기존 외관 복귀 버튼은 \`← 외관 다시 보기\`. 안심하는 문장을 곁들이되 강제 클릭/스크롤 차단 없음. 자바스크립트 미실행 시 새 이미지 위 보조 버튼 비활성.
3. **04 세 문장**: 각 행이 독립적으로 눈에 들어오도록 약 62svh 데스크톱·49svh 모바일의 자연스러운 공간을 할당. 현재 화면 중심의 가장 가까운 행 한 개에만 \`is-word-active\`를 적용해 나머지 문장을 조금 낮은 명도로 표현, 마지막은 세밀한 입체감 부여. 기존 GSAP ScrollTrigger의 세 문장 움직임을 바꾸거나 중복 소유하지 않는다. reduced-motion/Save Data/JS 미지원 환경은 모든 문장을 읽기 쉽게 표시. 스크롤 pin/snap/lock 없음.
4. **푸터**: 기존 링크를 기능별로 재배열하고, 브랜드 시그니처·근거·체험·진단 CTA를 배치. 공식 확인 전 회사 상호·등록번호·주소를 추가하지 않음. \`/#cases\`, \`/#flow\`, \`/privacy/\`, \`/my-store/\`, \`/\` 경로 유지.
