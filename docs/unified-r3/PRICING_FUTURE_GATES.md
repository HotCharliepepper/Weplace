# 내부 가안 — 고객 페이지에 포함하지 않음

일반 심화 진단 30~50만 원, 링크 수신자 한정 진단 5~10만 원 범위는 미확정 검토안이다. 승인된 판매가·할인·현재 결제 가능 상품이 아니다.

기존 0원 첫 화면 점검과 향후 유료 심화 진단은 제공 범위, 결과물, 담당자, 납기, 가격을 별도 확정해야 한다. 이번 고객 화면은 첫 화면 진단 **문의**만 제공한다. 가격·할인·결제 SDK·결제 버튼·공개 가격 JSON 없음.

실제 판매 전에 판매 주체, VAT, 범위와 납품물, 납기, 환불, 대상 조건, 정책 문구와 사용권을 확정하고 별도 승인·브랜치에서 구현한다. 이 문서는 `docs/`에만 있으며 기존 빌더의 배포 폴더에 포함되지 않는다.
