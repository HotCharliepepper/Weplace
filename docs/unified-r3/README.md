## 자료와 이미지

- 수치 출처는 기준 `index.html`의 hero-evidence와 `assets/js/main-landing-r2.js`의 사례 A 상세이다. 이번 작업은 기존 코드에 기재된 자료·산술을 대조했으며 원본 매출 장부나 POS를 독립 검증한 것이 아니다. 익명 음식점 A와 루위 사진을 같은 사례로 단정하지 않는다.
- 히어로와 길 안내: 기존 `/img/weplace-hero-surface.jpg` (1672×941, 188,239 bytes). 실내 사진보다 문턱과 열린 문의 기대감이 분명하여 PR #31의 선택을 유지. object-position 70% 53%, 모바일 265px. 실제 고객 공간으로 표기하지 않는다. 이미지 권리 원증빙은 새로 확인되지 않았으므로 운영 승인 때 재확인한다.
- 사진 체험: 기존 `assets/hero-r2/memory.webp`, `room.webp`. 신규 이미지 생성·외부 이미지 CDN·배경 영상 없음. 명시적 크기와 lazy loading, 실패 안내.
- 서체: 기존 로컬 RF Sans, Noto CJK 기반 누락 글자만 `Unified Supplement`로 보충. OFL 사본 포함, `font-coverage.json`에 글자·바이트·SHA. 본문 13–15px, 수치·제목 크기/무게/간격으로 위계. 모든 글자를 두꺼운 그림자로 처리하지 않는다.
- GSAP 3.13.0/ScrollTrigger 로컬 파일 재사용. `unified-r3.js`만 페이지를 제어한다. 과거 세 컨트롤러를 동시에 불러오지 않는다. 음원은 기존 `resolute-sonic-a.js`의 190ms 합성음만 import.
