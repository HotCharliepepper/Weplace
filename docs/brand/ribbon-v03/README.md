# Weplace R2 — Shared Ribbon v0.3

PR #12의 최신 R2를 보존하는 별도 브랜치입니다. main `42562ec1`, PR #11 `3c1278c3`, PR #12 `afaaa22f`를 확인한 후 작업했습니다.

## 구현

- A Fold Route를 `#changes`, C Double Signal을 `#process` 제목 주변에 각각 한 번 배치했습니다. 원본 SVG 그대로 사용하며 장식은 기본 정지, 빈 alt와 aria-hidden, 명시적 크기를 갖습니다.
- 기존 크림/테라코타, 타이포그래피, 로고·파비콘, 실제 차트, 사례, FLOW와 인증 구조는 보존했습니다. ZIP의 파일은 장식 시안이며 공식 CI나 파비콘 교체본이 아닙니다.
- 공통 footer의 Mashcore 링크를 `https://mashcore.co.kr/`로 변경했습니다. 소스 스냅샷 33곳과 생성 기준 config의 URL만 일치시켰습니다.
- 새 문장의 세 글자(궁·묻·없)를 같은 Pretendard에 추가했습니다. 서체를 교체하지 않았습니다.

## 감정 흐름과 언어

관측 수치 → 우리 매장의 빠진 안내를 떠올리는 질문 → 눈으로 보는 구성 비교 → 검색에서 확인할 정보 → 사례의 비교 근거 → 작업 확인 방식 → 작은 첫 실행 순서입니다.

`손님이 묻지 않는다고 / 궁금한 게 없는 건 아닙니다.`를 #changes에 한 번 배치했습니다. 문의가 없다는 사실을 관심이 없다는 결론과 동일시하지 않도록 하는 문장입니다. 매출 인과나 심리 효과가 실증됐다고 주장하지 않습니다. 이후 사진·정보·예약 순서의 구체 비교가 이어집니다.

첨부 im-not-ai의 humanize-korean Codex Light 경로로 독립 윤문과 최종 대조를 했습니다. 일반 설명의 쉼표 10곳을 정리했습니다. 검수 대상 본문의 문자 변경률은 0.27%, 수치·서법 소실은 0입니다. 보호한 사례/증거 문구의 쉼표 2곳은 규칙상 WARN으로 남겼습니다. 최종 accept, 등급 C / 자체검증 5/6은 이 보존 예외를 포함한 해당 도구의 판정이며, 인간다움이나 성과의 실측 점수가 아닙니다. 새 인식 문구는 별도 편집이므로 이 변경률에 포함되지 않습니다.

## 검증과 운영 전환

`npm run verify`: 74개 통과, HTML 34개 / 참조 1,056개 / 내부 결함 0. 세부 사항은 qa.json과 test-results.txt를 확인하세요. 200%는 CSS 확대 대체 검수이며 네이티브 브라우저 확대는 NOT RUN으로 기록했습니다.

현재 턴의 배포 권한은 승인으로 이해했습니다. 그러나 실제 운영 빌드는 회사/개인정보 확인 22건과 방침 초안 마크업 1건 때문에 실패합니다. 사업자번호·주소·개인정보 담당 정보와 개인정보 운영 확인을 임의로 작성하지 않았습니다. release-readiness.json에 필요한 값과 확인 항목을 적었습니다. 기존 운영 사이트는 유지되며, 검토용 Preview는 noindex입니다.
