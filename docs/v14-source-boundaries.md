## 4. 새 검사의 의도

1. **검색·no-JS 본문:** 네 업종의 질문·고유 이미지·다음 행동이 JavaScript/API 응답 없이 초기 HTML에 있는지 확인한다.
2. **기능 숫자의 출처:** 화면의 4/8/6을 실제 업종 선택 수·목적 조합 수·진단 문항 수와 비교한다. 고객 수·성과로 취급하지 않는다.
3. **비교 정보의 일치:** 접힌 비교표의 정리 전/후 내용이 같은 체험의 실제 표시 내용과 맞고, 업종·목적 변경 후 이전 표가 남지 않는지 확인한다.
4. **자율 펼침:** 기본 `<details>/<summary>`를 사용해 no-JS에서도 읽을 수 있게 한다. 공개 API 재조회에서 열린 보조 내용과 초점을 보존하되, 만료 수치는 숨긴다.
5. **언어 짝:** 실제 있는 한국어/영어 대응 페이지만 상호 연결하며, 자기 canonical·hreflang·HTML lang·Open Graph·sitemap·구조화 데이터가 일치하는지 확인한다.
6. **데이터 경계:** 글로벌 페이지에 신규 수집 폼·실행 스크립트·가격 Offer·성과 그래프·자동 이동을 추가하지 않는다. 문의는 기존의 명시적 링크로 연결한다.

자동 검사로 입증할 수 없는 문장 자연스러움, 구매 검색 의도, 모바일 터치감, 실제 화면 낭독기·OS 모션 설정, 실기기 성능은 별도 편집 및 브라우저 검수 기록에서 구분한다.

## 5. 운영 전 남은 승인

- 글로벌 서비스의 실제 국가·언어·응대·납품·계약·정산 범위와 원어민 편집 확인.
- 회사 정보의 최신 증빙 및 개인정보 처리·위탁·국외 이전·보유/삭제 절차의 운영/전문가 확인.
- 실제 고객 사례·사진·성과 수치의 근거와 공개 허가.
- 신규 추적·자동 저장·CRM 분류·권한 변경·계약/결제 기능의 별도 실행 승인.
- 최종 main 병합 및 운영 배포 승인.

이 문서는 위 항목을 승인하거나 운영 배포가 완료되었다고 선언하지 않는다.

발견한 결함: 공개 기록의 펼침 버튼이나 기록 링크에 초점이 있는 동안 승인 데이터가 만료되면 해당 컨트롤이 사라져 문서 본문으로 초점이 빠졌다. 수정 후에는 사라진 컨트롤이 속했던 업종의 summary로 초점을 돌린다. 이때 이전 수치와 기록은 표시하지 않으며, 일반 보조 설명의 열린 상태는 유지한다. 정상 재조회에서는 기존 컨트롤의 초점을 그대로 보존한다.

검사 도구 자체의 조정: 초기 시도에서 과거 별칭 페이지의 본문 전체·canonical이 동일하다고 가정했으나, 기존 안내 배너·하위 업종명·독립 canonical을 갖는 페이지였다. 이는 제품 결함으로 기록하거나 강제로 변경하지 않았다. 새 회귀 검사는 실제 연결된 업종 페이지의 정보 일치에 한정한다. 별칭 URL 정리는 향후 검색 구조 검토 대상이다.

위 결과는 DOM·기능·공개 경계의 자동 검사다. 화면 폭·키보드 실제 렌더링·모바일 터치·200% 확대·OS 설정·Lighthouse 결과는 이 숫자에 포함되지 않으며, 별도 브라우저 검수 기록을 따른다.
