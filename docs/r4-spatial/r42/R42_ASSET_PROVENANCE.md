## 음식 사진과 이전 구성

기본 사진은 사용자가 이전에 제공한 1254×1254 PNG입니다. 업로드 기록은 2026-10-11이며, 해당 기록은 모델 생성 여부를 false로 표시합니다. 이는 촬영자·카메라 원본·촬영일·보정 이력을 독립적으로 입증하지 않습니다. 공개 표기는 **루위의 기존 제공 사진**으로 제한했습니다.

이번 구현은 제공 PNG를 너비 640px와 1254px로 리사이즈하고 WebP 품질 85로 인코딩했습니다. 사진 내용 생성·합성·배경제거·재구도 작업은 포함하지 않습니다. 사진 선택 비교는 기존 제공 제안 자료의 루위 전후 캡처 및 설명과 대조했습니다. 해당 내부 HTML 전체, 무관한 고객 정보, 내부 가격과 자료 식별자는 공개 저장소에 옮기지 않았습니다.

## 공개 화면의 사실 구분

- 사진과 비교는 **제공 자료의 사진 선택 비교**입니다. 베이징덕 사진 선택이 매출 변화를 일으켰다고 주장하지 않습니다.
- 아래 메뉴·자리·예약 안내는 화면 구성 예시입니다. 실제 루위의 예약 조건이나 예약 확정 기능으로 표현하지 않습니다.
- 캡처에 포함된 리뷰 수·영업시간·주차 정보를 현재 매장 운영 사실로 복사하지 않았습니다.
- 음식점 A의 매출 관측값은 별도 기록입니다. 사진 속 매장과 동일한 매장이라고 연결하지 않습니다.
- 제공 자료의 확보와 촬영자·권리자·원본 라이선스·최종 운영 공개 권한 확인은 서로 구분합니다. 본 문서는 추가 운영 공개 승인을 대신하지 않습니다.

## 브랜드 자산

사진 3의 접힌 W, 세이지·포리스트, 금색 점과 `Weplace,` 표기를 **웹용 벡터로 재구성**했습니다. 원본 벡터 복원이나 픽셀 동일성을 주장하지 않습니다. 워드마크 윤곽선은 저장소의 Pretendard SemiBold에서 만들었고, 기존 SIL Open Font License를 보존했습니다. 상세 생성 방식과 폰트 출처는 [brand/README.md](brand/README.md), [brand/font-provenance.json](brand/font-provenance.json), [brand/FONT-LICENSE.txt](brand/FONT-LICENSE.txt)에 있습니다.

헤더·공통 footer는 400:90 가로 로고 비율을 사용합니다. favicon은 작은 크기용 W와 점으로 단순화했습니다. 배포 SVG에는 외부 이미지·폰트·스크립트 의존성을 추가하지 않았습니다. OG는 1200×630 JPEG이며 기존 메시지를 사용하고 새로운 성과·가격 주장을 넣지 않았습니다.
