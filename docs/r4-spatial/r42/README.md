# R4.2 · 음식 사진과 웹 브랜드 업데이트

작성일: 2026-11-03  
작업 브랜치: `draft/weplace-r42-brand-food-20261103`  
비교 기준: R4.1 `cd860cb04ce0650d3a6d222e7f1f7b235e3a8c13`

## 목적과 결과

사용자가 선택한 밝은 크림 바탕, 큰 메시지, 여백과 매출 차트의 구성을 유지하면서 음식 사례와 브랜드 자산을 정리합니다. 마사지 예시였던 사진 선택 장면을 루위의 기존 제공 음식·외관 자료로 바꾸고, 사진뿐 아니라 설명·질문·탭 상태까지 음식점 맥락에 맞췄습니다.

로고·파비콘·공유 이미지는 사용자가 선택한 접힌 W와 금색 점의 인상을 웹에서 사용할 수 있도록 정리했습니다. 포리스트·세이지·골드 계열로 주요 색을 맞추고, Mashcore의 관점에서 Weplace의 실행으로 이어지는 설명과 링크를 추가했습니다.

이 문서는 구현 변경과 실제 확보한 검수 증빙을 정리합니다. Draft PR의 최신 HEAD·Netlify 배포 식별자는 PR 본문의 배포 기록을 함께 확인하세요. 미실시 검수는 별도로 명시합니다.

## 1. 유지한 기준

- Hero의 좌측 메시지·우측 차트, 큰 제목과 짧은 문장, 밝은 바탕과 여백.
- 현재 표시된 `1.72억 → 1.93억`, `+12.2%`, `2,100만 원`, 2026년 5–6월 기간과 관측값의 단서.
- **첫 화면 진단 · 0원 · 매장 1곳 · 공개 채널 1개 · 직접 써볼 개선안 1개**라는 공개 약속.
- 결과물 설명과 신청 화면에서 생성되는 요청문의 범위.
- 기존 Hero·사진 선택·FLOW의 3장면 모션 소유권, 정적 폴백과 움직임 감소 대응.
- 공개 FLOW 체험과 실제 고객·직원 운영 화면의 구분.

게임처럼 작업과 연락을 확인하는 FLOW·CRM 확대는 다음 차수입니다. 이번 FLOW 변경은 공개 시연의 작업 설명을 음식 사진·식사 안내와 맞춘 범위입니다.

## 2. 사진 선택 장면

기본 상태는 **메뉴 먼저**, 비교 상태는 **외관 먼저**입니다. 베이징덕 사진에서 메뉴·식사 자리·예약 안내로 이어지는 순서를 보여줍니다.

| 변경 | 실제 동작 |
|---|---|
| 사진과 탭 | 선택 시 이미지 `src`, `srcset`, 크기 정보, 대체 텍스트를 함께 갱신 |
| 반응형 후보 | 음식은 640px·1254px WebP 후보를 사용. 외관 상태로 바꾸면 음식의 `srcset`을 제거하여 잘못된 후보가 남지 않게 함 |
| 설명 | 대표 메뉴·메뉴 구성·자리·인원·예약 안내로 탭별 제목과 설명 통일 |
| 질문 | `대표 메뉴` / `식사 자리` / `예약 안내` |
| 다음 행동 | `예약 방법 확인하기`를 누르면 안내 구성 예시를 펼침 |
| JS 없는 상태 | 기본 음식 사진과 텍스트 비교, 질문별 설명을 읽을 수 있음 |

원본 외관 캡처는 변경하지 않고 CSS에서 외관·차량 영역을 보여줍니다. 화면 예시에 인물·플랫폼 리뷰 수·영업시간이 들어오지 않도록 표시 영역을 검수합니다.

### 사진과 예시의 구분

- 사진은 루위 사례의 **기존 제공 자료**입니다. 이번에 새 음식 이미지를 생성하지 않았습니다.
- 표기는 **루위 · 사진 선택 비교**입니다. 정확한 촬영일·사진 교체일을 확인했다고 주장하지 않습니다.
- 메뉴·인원·가격·예약의 구체적인 조건을 새로 만들어 넣지 않았습니다. 아래 안내와 버튼은 화면 구성 예시입니다.
- 이 장면은 실제 예약을 확정하거나 외부 예약 채널로 제출하지 않습니다.
- 사진 선택과 매출 관측값 사이에 개별 인과관계를 추가하지 않습니다.
- 촬영 원본·최초 권리자·최종 운영 공개 범위는 별도 확인 대상으로 남깁니다.

사용 자산은 `assets/home-r42/`에 있습니다. 관련 없는 내부 원자료와 제안서 전체는 공개 소스에 포함하지 않습니다.

## 3. 로고·아이콘·색상

`assets/brand/r42/`의 SVG는 **사진 3을 기준으로 만든 웹용 벡터 재해석**입니다. 원본 래스터의 질감·정확한 글꼴·모든 곡선을 그대로 복원한 파일은 아닙니다. 헤더와 작은 아이콘에서 읽히는 접힌 W·금색 점·`Weplace,` 표기를 기준으로 정리했습니다.

| 자산 | 적용 |
|---|---|
| `weplace-logo-light.svg` | 밝은 배경의 헤더와 공통 footer |
| `weplace-logo-dark.svg` | 어두운 배경용 로고 자산 |
| `weplace-symbol.svg`, `weplace-symbol-flat.svg` | 심벌과 작은 크기용 단순화 심벌 |
| `favicon.ico`, `favicon-32.png`, `favicon-96.png`, `favicon.svg` | 브라우저·검색 표시용 아이콘 |
| `apple-touch-icon.png` | 모바일 홈 화면 아이콘 |
| `og-weplace-r42.jpg` | 1200×630 링크 공유 이미지 |

기본 크림 배경은 유지하고, 본문 `#20352D`, 주요 행동 `#285247`, 세이지 `#AAB69E`, 골드 `#C8A56B`를 중심으로 맞췄습니다. 골드는 점·보조 표시 역할로 사용하고, 밝은 배경의 작은 본문에는 더 어두운 색을 사용합니다. 최종 대비·포커스·실제 렌더링 확인은 브라우저 검수 기록과 구분하여 남깁니다.

공통 footer는 `scripts/company-info.mjs`의 생성 원본에서 로고를 바꿨습니다. 회사정보·개인정보의 내용과 공개 승인 상태를 BI 변경과 함께 수정하지 않습니다.

### Preview 공유 이미지

운영 사이트에는 아직 없는 새 OG 이미지가 검토 URL에서 열리도록, 비운영 빌드에서 새 R4.2 이미지의 출처만 검증된 Netlify Preview 주소로 맞춥니다. 운영 canonical과 `og:url`은 유지합니다. 허용된 HTTPS Netlify 주소만 사용하며, 주소가 유효하지 않으면 임의 외부 주소를 넣지 않습니다.

검색 결과 파비콘 반영이나 메시지 앱의 캐시 갱신까지 완료됐다는 뜻은 아닙니다.
