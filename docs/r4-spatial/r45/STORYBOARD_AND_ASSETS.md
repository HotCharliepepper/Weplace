## 자산 / 승인

- 루위 640/1254 WebP는 PR20과 바이트 동일. 사용자 요청 범위에서 기존 검토용 재사용. 새 합성·AI 변형·영상 변환 없음. 촬영자·차기 운영 공개 라이선스는 별도 확인 필요.
- Folded W는 `assets/brand/r42/weplace-symbol.svg` 그대로 사용. 기존 브랜드 색상과 금색 점 보존.
- 신규 비실사 장식은 SVG 선·CSS 빛·타이포 도식뿐입니다. 실재 객실·시설·사람을 생성하거나 외부에서 다운받지 않았습니다.
- 숙박 고객 원본 미디어 등록원장을 재확인한 결과 12개 슬롯은 AWAITING_UPLOAD. 원본·객실 일치·사용권·고객 공개 승인·실제 채널 적용은 미확인입니다. 고객명·원본·내부자료는 public artifact에 넣지 않았습니다. 5단계 사진 순서만 일반적인 선택 예시로 구현했습니다.
- 첫 진단은 가상 C의 제작 예시. 실제 진단·자동 분석·신청 접수·예약 완료가 아닙니다.
- 신규 한글 15자는 공식 Pretendard 1.3.9 OFL 원본으로 보충. Regular 2,012B / SemiBold 1,988B, 누락 0. 원본 폰트 서브셋은 보존.

## 추가 영상 소스 — 이번 구현에서는 불필요

검증된 새 영상은 확보되지 않았고 영상 파일·Runway 생성·AI 변형은 적용하지 않았습니다. 현재 8초 표현은 코드로 완결됩니다. 향후 실제 영상이 필요하면 촬영 원본 식별자, 촬영자/사용권, 고객 공개 승인, 편집·AI 변환 허용 범위를 먼저 확인해야 합니다. 적용하더라도 같은 우측 사진 영역의 대체 질감으로만 사용하며 무음·1회·정지·실패 포스터 조건을 유지합니다.
