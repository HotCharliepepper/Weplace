## 변경

‘손님이 어디서 망설이는지, 먼저 확인해 보세요.’를 앞에 두고, 현재 화면 관찰·망설임 지점·우선 개선안 한 가지·직접 적용할 순서를 먼저 보여줍니다. 이 네 요소는 공개 채널 한 곳에 대한 개선안 한 가지의 설명입니다.

이후 첫 화면 진단 0원, 매장 1곳·공개 채널 1개·직접 써볼 개선안 1개, 계정 접속·실제 수정 제외, 수동 요청문 준비 순서가 이어집니다. 헤더·Hero CTA·진행방식 첫 카드·진단 폼의 상품명도 통일했습니다.

데스크톱 결과 카드는 4열, 모바일은 2열입니다. 하단 가격·폼은 데스크톱 2열, 모바일 1열입니다. 기존 폼 구조와 공유 버튼 컴포넌트, R4 색상·간격 변수와 텍스트 스타일을 재사용했습니다. 결과 카드는 크기별 로컬 컴포넌트를 만들고 각각 4개 인스턴스로 구성했습니다.

## 검증과 한계

- 진단 섹션은 편집 가능한 텍스트·프레임·컴포넌트 인스턴스입니다. 전체 UI를 이미지로 대체하지 않았습니다.
- 첫 구성 후 가로 넘침 0, 진단 섹션 이미지 채움 노드 0을 확인했습니다.
- Hero·Store C·FLOW 노드의 내용·위치·크기는 Hero CTA 문구를 제외한 전후 직렬화 비교에서 동일했습니다. 진단 섹션 확장으로 아래 섹션의 세로 위치는 자동 재배치됩니다.
- 데스크톱 1440×1297, 모바일 390×1773 진단 섹션 PNG를 확인했습니다. 모바일 본문의 끝 단어 줄바꿈을 보정하고, 가격 카드 위 테두리를 웹과 같은 trust 색으로 맞춘 최종 화면입니다.
- Figma는 기존과 동일하게 Noto Sans KR를 사용합니다. 연결된 Figma 환경에 Pretendard가 없어 웹의 Pretendard와 글꼴·픽셀 동일성을 주장하지 않습니다.
- 이 변경은 확인된 공개 첫 화면 진단 범위만 포함합니다. 별도 상품 검토 자료는 이 Figma 파일에 게시하지 않았습니다.

`change-ledger.json`에 노드 변경·구조 검증 결과를 기록했습니다. `desktop-diagnosis.png`와 `mobile-diagnosis.png`는 Figma 출력이며 브라우저 실화면과 구분합니다. 캔버스 변경용 작업 스크립트는 전달 실행기로 제공하지 않습니다.
