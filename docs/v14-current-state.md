## 이전 화면과 최신 구현의 차이

최신 Preview의 네 카드는 각각 식사 공간, 커피와 좌석, 객실, 뷰티 거울·상담 그림을 사용하고 있었다. 따라서 같은 이미지를 네 번 쓰는 결함으로 간주하지 않았고 원본 SVG 네 개를 유지했다. 해당 이미지는 업종 이해용 예시이며 고객의 실제 제작·납품 자료가 아니다.

시작 시점의 카드 질문은 “부모님 모시고 가도 괜찮을까?”, “여기서 편하게 머물 수 있을까?”, “사진 속 방이 내가 예약할 방일까?”, “나에게 맞는 상담을 받을 수 있을까?”였다. 실제 브라우저 Before 기록은 390px·1024px 검토 iframe에서 촬영했다. 첨부 화면의 촬영 시점이나 버전을 확인했다고 주장하지 않는다.

수정은 이미지 교체보다 방문 상황의 구체화, 기본 CTA 노출, 선택적으로 읽는 설명, 정적 하위 페이지의 업종 차이에 집중했다. 기존 v1.3 모션과 8개 체험·6문항 진단을 보존한다.

## 변경 경계

새 글로벌 페이지는 검토용 noindex이다. 실제 검색 노출·수요·전환 성과를 입증한 페이지가 아니다. FLOW 인증·CRM·권한·공개 승인 API와 원본 데이터는 변경하지 않았다. 회사·개인정보의 22개 승인 확인 조건 및 production build 차단은 유지했다.
