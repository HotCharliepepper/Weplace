| 기업·기관 담당자 | `/enterprise/` | 범위·결과물·기능 예시·공개 기록 | `/process/` → 문의 |

## 기술 선택

| 선택 | 판단 |
|---|---|
| 기존 HTML/CSS | 채택. 본문·링크·절차가 JavaScript 없이 읽힘. 기존 SEO/배포/사이트 경계 유지 |
| 기존 React를 공개 사이트 전체로 확장 | 보류. 두 정보 페이지에는 상태 관리/라우터 교체 이득이 작음 |
| Next.js 또는 다른 프레임워크 이전 | 보류. 승인·인증·배포 경로 변경 부담 |
| GSAP/Three.js/Spline | 사용 안 함. 설명에 필수인 움직임·공간 조작 없음 |

Mashcore의 `질문 → 근거 → 산출물 → 절차 → 다음 행동` 원칙만 현장 언어에 적용했다. 연구 장면·브랜드·성과 수치를 이식하지 않았다. 신규 경로는 noindex 검토 상태이며 sitemap/운영 canonical 공개는 승인 이후 과제다.

- `npm run verify`: 자동 테스트, 전체 로컬 링크 검사, review 빌드.

- 새 페이지에 신규 runtime JavaScript 없음. 모션은 hover CSS이며 reduced-motion 규칙 제공.
- 회사/개인정보의 기존 22개 운영 게이트는 유지. 이 Draft가 이를 확인 완료 처리하지 않음.
- main 병합, production 배포, DNS, 인증, DB, 실제 파일 저장소와 실제 입찰 제출은 수행하지 않음.
