## 1. 이번에 보여주는 숫자의 의미

이번 패치의 주 시각은 **현재 이용할 수 있는 기능의 구성**이다. 고객 수, 납품 수, 예약 증가, 매출, 검색 노출 실적으로 해석하지 않는다. 실제 고객 성과 데이터가 확보되지 않았으므로 KPI 막대·추이·전환율 그래프는 게시하지 않았다.

확인 시점은 2026-10-19의 이번 소스와 테스트 실행 시점이다. 기능 구성 수에는 관측 기간·사용자 표본이 적용되지 않는다. 이후 업종·목적·질문을 추가하거나 삭제하면 표시와 검사를 함께 갱신해야 한다.

## 2. 기능 도식과 비교표의 표현 규칙

- 홈의 `4 → 8 → 6`은 서로 다른 단위의 기능을 소개한다. 모집단의 감소나 단계별 전환율처럼 막대 길이·면적·비율로 비교하지 않는다.
- 실제 조작은 **업종 하나 선택 → 해당 업종의 상황 하나 선택 → 정리 전/후 비교 → 원하는 경우 6문항 진단**이다. 여덟 상황을 모두 거쳐야 하는 절차가 아니다.
- 숫자와 의미를 읽을 수 있는 HTML로 제공한다. 색·그림만으로 단위를 전달하지 않는다.
- 비교표는 제목, 세 개의 열 머리글, 행 머리글을 갖는다. 표의 정리 전·후 내용은 예시 화면에서 사용하는 값과 동일하다.
- 비교표는 독자가 펼칠 수 있다. 정리 전/후를 바꿔도 열린 상태를 유지하고, 업종·방문 목적을 바꾸면 이전 표를 지우고 닫는다.
- 요식업의 8명처럼 실제 서비스 조건으로 오해할 수 있는 상황 수치는 예시임을 표시하고, 상세 안내에서 실제 수용 인원·조건 확인이 필요함을 밝힌다.

## 3. 기존 공개 관리 현황과 새 성과 차트의 구분

기존 `/api/weplace-industries`는 이미 마련된 공개 승인 정보의 읽기 경로다. 이 패치는 새로운 고객 실적 자료를 수집하거나, 해당 값을 KPI 그래프로 바꾸지 않는다.

공개 관리 수치에는 기존 `managedCount`, `capacity`, `remaining`, `capacityReviewedAt`, `activeUntil` 검증을 그대로 적용한다. 형식·수치 일관성·승인 확인 시점·기한을 통과한 경우만 표시한다. 알 수 없는 업종, 중복 레코드, 만료·조회 실패·이전 응답의 역전은 유효한 실적으로 받아들이지 않는다.

- 자료 없음·조회 실패·승인 만료를 `0곳`으로 바꾸지 않는다.
- 실제 승인된 `remaining: 0`과 미확인 `null`을 구별한다.
- 관리 중인 매장 수는 작업 성과나 고객 만족도를 뜻하지 않는다.
- 관리 한도와 잔여 수치로 즉시 착수가 가능하다고 약속하지 않는다. 일정은 상담으로 확인한다.
- 공개 기록과 수치는 보조 설명에서 읽는다. 업종 체험의 직접 이동 버튼은 접힌 영역 밖에 둔다.

## 4. 미래 실데이터 차트의 필수 계약

아래 항목은 차트를 공개하기 전에 작성해야 하는 명세다. 비어 있는 칸을 임의 추정으로 채우지 않는다.

| 필드 | 필요한 내용 | 미확인 시 처리 |
|---|---|---|
| `metric_id` | 중복되지 않는 내부 지표명 | 차트 생성 보류 |
| `definition` | 무엇을 어떤 사건으로 집계하는지. 클릭·문의 접수·예약 확정·계약을 분리 | 정의를 먼저 합의 |
| `unit` | 회, 건, 명, 원, % 등 | 축·라벨 표시 보류 |
| `denominator` | 비율의 분모, 중복 제거 기준, 필터. 단순 건수는 해당 없음의 이유 | 비율 계산 보류 |
| `period_start`, `period_end` | 시작·종료 시각과 포함/제외 규칙 | 전후·추이 비교 보류 |
| `timezone` | 원본 및 보고 기준 시간대 | 일·월 경계가 섞이지 않도록 먼저 정리 |
| `source` | 자료 소유자, 원본 시스템, 추출 파일/조회 조건, 보관 위치 | 출처 없는 숫자는 공개하지 않음 |
| `last_verified` | 마지막 원본 대조 시점·검수자 | 최신이라고 표기하지 않음 |
| `permission` | 공개 승인자·일자·사용 범위·만료/철회 조건 | 공개 보류. noindex로 대신하지 않음 |
| `status` | `CONFIRMED`, `NEED_VERIFY`, `HYPOTHESIS` | 실적 표현 보류 |
| `coverage` | 매장·지역·국가·언어·채널·기기 등 포함 범위 | 다른 시장으로 일반화하지 않음 |
| `missingness` | 실제 0, 미집계, 자료 없음, 비공개, 적용 불가의 구분 | 차트 공백·설명으로 표시. 0으로 대체하지 않음 |
| `comparison_rule` | 전후 기간 길이·요일·채널·분모의 비교 가능성 | 동일한 변화율로 결합하지 않음 |
| `attribution_note` | 작업 외 요인과 인과성 해석의 한계 | Weplace 작업이 증가분을 만들었다고 단정하지 않음 |

원본 자료와 고객 식별 정보는 공개 저장소·Preview·브라우저 스크립트에 넣지 않는다. 허용된 집계값과 공개 근거만 별도 승인한 뒤 사용한다. 제3자 도구의 계정 데이터 접근, 신규 추적 이벤트, CRM 자동 인입은 이 계약 작성과 별개의 실행 승인 대상이다.

## 5. 차트별 공개 전 확인

1. 화면 가까이에 정의·기간·단위·출처·공개 범위·가설 여부를 표시한다.
2. 비율에는 분모를, 건수에는 중복 처리와 집계 대상을 표시한다.
3. 동일 비교에 같은 축을 사용한다. 막대 축을 임의로 잘라 차이를 과장하지 않는다.
4. 색 외에 숫자·라벨을 제공하고, 읽을 수 있는 표 또는 텍스트 대안을 제공한다.
5. 클릭 증가를 문의·예약·매출 증가로 바꾸어 설명하지 않는다.
6. 전국 통계로 특정 상권의 고객 수를 계산하지 않는다. 한국 매장의 외국인 손님과 해외 매장의 한국인 손님을 별도 범위로 다룬다.
7. 가상 계산이 필요하면 독립 검토 화면에서 입력값과 산식을 함께 보이고, 산술 결과가 예측·성과·보장이 아님을 같은 화면에 표시한다.
