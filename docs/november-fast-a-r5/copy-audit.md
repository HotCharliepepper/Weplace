## Ⅱ. 감정/장면 진단 (목표값일 뿐 실제 반응 아님)

| 장면 | 역할 | 의도한 전환 | R4의 걸림 | R5의 변경 |
|---|---|---|---|---|
| 01 ‘광고, 하지 마세요.’ | 소프트 반전(B) | 멈춤 → 궁금증 | 첫 문장이 기존 광고 경험을 단정하는 어조 | 조건부 인정으로 수정, 반전 질문 간결화 |
| 02 11월의 온기 | 인정/회복(G) | 화제 회복 → 여유 | ‘머무는 화면’, ‘이미 ~ 했을 겁니다’가 추상·단정 | ‘손님이 보는 화면’, 조건문 |
| 03 FAST | Gather–Burst–Gather (모션) | 기대 → 직접 보기 | ‘A DIFFERENT OFFER’가 확정 혜택처럼 해석될 여지 | FIRST LOOK으로 교체 |
| 04 가상 전후 | 직접 관찰(ILLUSTRATIVE) | 선택 → 작은 간격 확인 | 식당/좌석을 전 업종에 일반화 | 서비스·공간의 중립 표현과 정리 전/후 라벨 |
| 05 작업 방향 | 이유/선택 | 실제 작업 질문으로 전환 | ‘무엇부터 달라질까요’가 결과 예고처럼 들림 | ‘무엇부터 볼까요’로 변경 |
| 06 증빙/추가 정보 | Evidence 경계 | 예시·실적 혼동 방지 | ‘진행됐는지도’가 실제 진행 이력처럼 들릴 수 있음 | ‘진행 과정 예시’로 정리 |
| 07 다음 행동 | Agency/Rest | 비교 지속 or 문의 | 같은 11월 가상 안내 반복 | 보류 가능한 마무리로 간결화 |
| 08 문의 | 선택/복사/수동 전송 | 부담 없는 선택 → 카카오톡 | 30초 속도 단정 / 자동 전달 오인 / 내부식 장문 | 시간 보장 삭제, 직접 전송 명시, 짧은 고객 메시지 |

**G–B–G 예외:** 첫 문장이 B로 시작하는 것은 사용자 의도에 따른 국소 장치다. 동일 화면에서 ‘광고를 멈추라는 말은 아닙니다’와 구체 질문으로 회복시키고, 이후 11월 장면에서 이미 해본 노력을 존중한다. 모션의 Gather–Burst–Gather와 혼용하지 않는다.

| 밝은 히어로 | 광고 이후, 손님이 머무는 화면을 다시 볼 차례입니다. | 광고 다음, 손님이 보는 화면을 살펴볼 차례입니다. | ‘머무는’ 비유를 실제 온라인 행동으로 |

| 작업 계획 | 그 화면을 바꾼다면, 무엇부터 달라질까요? | 그 화면을 바꾸려면, 무엇부터 볼까요? | 결과 약속보다 확인할 과정 |
| 문의 제목 | 30초 선택 문의 | 선택으로 문의 준비 | 미검증 속도 주장 삭제 |
| 03 단계 | 카카오톡으로 전달 | 붙여넣어 보내기 | 복사와 실제 전송을 구별 |

| 문의 미리보기 | 완성될 문의 문장 확인하기 | 완성된 문의 내용 미리 보기 | UI의 실제 동작 설명 |

## Ⅳ. 고객이 받게 되는 문의문 예시 (가상 선택 조합)

**선택:** 기존 상담 / 숙박 / 찾아오는 길 / 주차 문의 반복 / 비용·일정

```text
[Weplace · 11월 화면 비교 문의]
안녕하세요. 전에 Weplace와 상담하거나 함께 일한 적이 있습니다.
업종: 숙박
살펴보고 싶은 화면: 찾아오는 길
지금 고민: 주차·대중교통 문의가 반복돼요
가능한 작업 범위와 비용·일정을 알려주세요.
```

기존 R4는 매장명 제공 약속, 진단 범위·비용·일정 결정을 고객이 먼저 선언하는 등 운영 내부 문서 같은 부분이 있었다. R5는 요청 내용만 남긴다. 실제 고객과의 이력은 고객 선택일 뿐 회사의 확인된 거래 기록이 아니다.

## Ⅴ. 검수와 남은 한계

**기능 회귀 기준:** H1 하나, 안내/가상 예시 레이블, 3선택·전후 비교, 주제별 동적 문제·문의문, 기존 상담 분기, 복사/카카오 채팅 URL, 변경 시 현재 고민 초기화, reduced-motion, 브라우저 오류/POST 0.

**현장 검증용 질문 (내부 테스트 대상 2~3명):**
1. 첫 문장을 보고 Weplace가 광고를 무조건 중단하라고 한다고 이해하셨나요? (오해 확인)
2. 사진·길·예약 중 무엇을 먼저 비교하고 싶으셨나요? (실제 우선순위)
3. 문의 화면의 버튼만 보고, 카카오톡에서 무엇을 해야 하는지 알 수 있나요? (전송 책임)
4. 지금 문의하지 않기로 해도 필요한 정보를 얻었다고 느끼셨나요? (보류권)

**이번 작업에서 검증하지 않은 것:** 외부 카카오 광고 효과, 실제 방문자의 감정 수치·계약률, iPhone/카카오 인앱의 복사 허용, 자동 Sheets 저장, 실제 회사정보·개인정보방침 및 공개 혜택 승인.

**운영 가드:** 본 문장은 검토용이며 R4/운영 main 덮어쓰기, 대량 발송, 결제·데이터 쓰기를 하지 않는다.
