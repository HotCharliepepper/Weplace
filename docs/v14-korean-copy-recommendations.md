## 편집 검수 기준과 남은 확인

1. 한 문장에 손님이 확인할 변수(인원·자리·시간·가격·준비·예약)가 보이는가.
2. 이 문장이 이미지와 같은 설명만 반복하는가, 이미지 다음에 필요한 답을 더하는가.
3. 서비스 결과물의 예시인지 실제 납품/사용/성과인지 구분되어 있는가.
4. 버튼을 누른 결과를 미리 알 수 있는가. ‘상담’과 ‘복사’, ‘계약’과 ‘검토’의 뜻을 섞지 않았는가.
5. 고친 단어가 프로그램의 값·선택/초점·복사 내용·업종 전달과 일치하는가.
6. 줄 길이·200% 확대·작은 화면에서의 읽기는 브라우저 검수 결과와 분리해서 보고한다. 이 대장 작성만으로 시각 검수 완료라고 표시하지 않는다.

한국어 자연스러움은 편집 검토 완료 상태이며, 실제 업주 대상 이해도·선호도 테스트는 미실시다. 문구 변화가 문의/예약을 늘렸다는 주장은 하지 않는다. 실제 적용·예외는 최종 통합 대장과 커밋에 남긴다.
