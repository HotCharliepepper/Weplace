# v1.2 브라우저 검수 기록

기준: 2026-10-19, PR #8의 `b20df3540d9c3b9300d8698c481f714958dc84ef` Netlify Deploy Preview. 검수 뒤 360px 안내물 제목 줄바꿈을 한 번 더 수정했다. 운영 배포가 아니다.

## 실제 확인한 범위

Chrome 클라우드 브라우저에서 `/review/audience.html`의 실제 iframe viewport 360·390·430px 및 데스크톱 홈페이지를 렌더링했다. 이것은 물리적 휴대폰/iOS/Safari 검수와 다르다. 데스크톱 스크롤바 때문에 내부 clientWidth는 설정 폭보다 15px 작았다.

## 검수 완료로 표시하지 않은 범위

- 결과 내려받기 버튼 클릭 후 화면에는 ‘다운로드 요청’ 상태가 나타났다. 자동화의 download 완료 이벤트는 시간 초과하여 실제 파일 완료는 확인하지 못했다.
- 인쇄 대화상자, 물리적 휴대폰/Safari/스크린리더, 실계정 2개의 고객별 권한 종단 검수는 미실시.
- 상담 메시지 발송, 예약 확정, 실제 계약·결제, 고객 데이터 작성/변경은 하지 않았다.
- FLOW 운영 로그인/가입에 새 정책 링크를 반영하지 않았다. 정책 확정과 별도의 소스 변경/검증이 필요하다.
- ‘이상한마케팅’ 레퍼런스는 공개 문서의 이야기 순서를 확인했으나 스타일 자산 로딩 실패와 재시도 시 403으로 정상 시각 검수는 완료하지 못했다. 고유 문장/디자인은 복제하지 않았다.
- 코드 테스트는 홈 43/43, FLOW 159/159이며 이는 위의 브라우저 미검증 항목을 대체하지 않는다.

## 배포 조건

법인/방침 검토 플래그와 시행일이 확정되기 전 production build는 차단된다. Preview는 검색 제외 헤더/메타를 붙이지만, 이것은 접근 제어가 아니다. 고객 미승인 자료·원문 개인정보는 배포 산출물에 넣지 않는다. 최종 운영 공개는 사용자의 별도 승인 사항이다.
