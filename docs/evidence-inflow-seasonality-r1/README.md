## 1. 05 — 실측 용어에 충실한 +168% 카드

카드의 \`+12.2%\`를 **플레이스 상세 페이지 유입수** \`877회(2026년 5월) → 2,350회(8월)\`으로 대체.

- 증가 건수: \`2,350−877=1,473회\`
- 증가율: \`1,473/877×100≈167.9589%\`, 반올림 \`+168%\`.
- 877회는 이미 유입이 발생하는 출발점. **동종 매장 대비 많았다는 주장은 근거 없음.**
- **유입률**보다는 **유입수 증가율**이 정확. \`CTR\` 또는 매출·방문 고객 수·예약률로 바꾸지 않는다.
- 클릭 시 06의 \`#inflow-evidence\`로 이동해 전후 건수/계산식/기간/출처 한계를 볼 수 있다.
- 날짜·수치는 사용자 제공 자료 기반. 실제 스마트플레이스 관리자 원본의 동일 지표·같은 집계 단위 확인과 고객 공개 허가는 **아직 미완료**.
- Weplace 작업의 직접 기여율·매출 인과는 입증되지 않았다.

## 2. 06 — 같은 4~6월, 네 연도의 다른 방향

사용자가 공유한 자료 원문:

| 연도 | 4월 | 5월 | 6월 | 사용자 제공 자료의 모호성 |
|---|---:|---:|---:|---|
| 2023 | 1.70억 | 1.79억 | ? | **원문에서 '2025년 6월 1.60억'이라고 기재됨**. 2023년 값으로 임의 이동 금지 |
| 2024 | 1.66억 | 1.96억 | 1.94억 | 5→6월 −1.02% |
| 2025 | 1.91억 | 2.02억 | 1.60억 또는 1.70억 | **6월 중복/상충 기재**. 두 경우 모두 5월 대비 하락 (−20.79% 또는 −15.84%) |
| 2026 | 1.74억 | 1.72억 | 1.93억 | 5→6월 +12.21% |

그래프는 연도별 작은 선형 차트 4개이고 **동일한 세로축 1.50–2.10억**으로 비교한다. 0부터 시작하지 않음을 명확히 표시하며, 숫자 왜곡 없는 원값과 SVG 접근성 설명을 넣었다.

- 2023년 6월 값: 그래프 비움.
- 2025년 6월 값: 두 **가능한 값의 점선과 범위 마크**를 사용. 단정적인 숫자나 평균점을 표시하지 않음.
- 2024·2025의 하락/2026의 상승이라는 **방향 차이**만 확정 가능한 범위에서 설명.
- **'4년 중 유일한 상승'은 2023년 6월의 정확한 원값이 확인되기 전에는 보류.**
- 새 데이터가 R3의 2026년 월매출 \`1.72억→1.93억\`과 같은 업장/같은 기준인지 원본 증빙으로 확인 전에는 공개 사례로 병합하지 않는다.

마지막 섹션은 2026년의 원값·계산식 및 기존 FLOW·사례 링크를 유지한다. **매출 증가 ≠ 서비스 기여율** 구분을 보존한다.

## 3. 동종업계 벤치마크와 LocalScope(상권나침반) 연구

별도 데이터 수집 프로젝트로 검토할 가치가 있다. 다만 **네이버 플레이스 개별 업체 상세 유입수와 지역/업종 전체의 상대 관심도를 같은 KPI로 비교하면 안 된다.**

- 네이버 스마트플레이스 사업주 통계는 **자기 업체의** 상세 페이지 유입 횟수, 채널, 키워드, 시간·요일 등에 대한 데이터다. 공개 안내 기준 최근 1년 조회: https://help.naver.com/service/30026/contents/20527?osType=PC
- 네이버 데이터랩 '지역별 관심도'는 지역·업종별 검색 후 지도 클릭 데이터를 활용한 **관심도/상대 추이**. '동종 매장 평균 월 유입 877회'라는 직접 비교 수치가 아님: https://help.naver.com/service/17528/contents/15801?lang=ko&osType=PC
- 플레이스 광고 성과에서는 광고주센터의 노출·클릭·CTR과 스마트플레이스의 광고 유입 이후 통계가 서로 다른 측정 단계: https://ads.naver.com/help/faq/759
- 합법적·권한 있는 동의 매장의 집계 데이터를 충분히 확보하면, 향후 익명화·최소 그룹 크기·표본 수·업종 분류·기간·지역 등 동일 조건으로 기준 범위를 연구할 수 있다. 비용·법적 근거·출처·수집 동의·편향·권한/삭제 정책을 먼저 설계.
- LocalScope와의 연동은 **미래 검토**. 기존 상권나침반 백엔드/분석 로직/DB/권한/결제는 이번 작업에서 절대 변경하지 않는다.
