## 동작
문의 영역에서 한 번에 질문 하나를 보여준다. 관계 → 업종 → 화면(사진/길/예약) → 현재 고민 → 원하는 안내, 이후 최종 요약이다. 각 버튼을 누르는 순간 다음 화면으로 이동하고, 이전 질문 버튼으로 돌아오면 기존 답을 유지한다. 이미 답한 질문은 보조 ‘다음 질문’으로 넘길 수 있다.

모든 질문이 완료되면 R5와 같은 자동 조합 문의문, 별도 내용 복사, 카카오톡 열기 링크가 보인다. 카카오톡 채팅창에 직접 붙여넣고 전송해야 실제 접수되며, 자동 전송·자동 저장·Google Sheets 저장은 없다.

'어느 화면부터 볼까요?'를 바꾸면 기존 고민이 초기화되고 다시 골라야 한다. R5의 세 필수 조건(업종·고민·원하는 안내)을 유지한다. 상담 관계와 앞서 체험한 화면은 기본값이 있으나 직접 변경 가능하다.

## 접근성 / 안전
- JS 없을 때는 기존과 같이 모든 질문이 보이며 공식 카카오 채팅 링크도 남긴다.
- JS 실행 시 한 장만 보이고 나머지는 숨김/inert 처리, ARIA 진행상태와 단계 제목 포커스, 키보드와 reduced-motion 대응.
- 장면 이동은 문의 영역 내부에서만, 광고 도입/FAST/비교/회사 링크는 변경하지 않는다.
- noindex,nofollow는 검토용이며 URL 접근 제한을 뜻하지 않는다.
- Google Sheets 저장/API, CRM, 인증, DB, 결제, 수집 동의, 카카오 고객 메시지 발송은 실행하지 않는다.
