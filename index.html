BEFORE WE MEET

궁금한 것은
먼저 확인하세요.

광고부터 시작해야 하나요?

먼저 손님이 검색·비교·예약하는 화면에서 필요한 답을 찾을 수 있는지 살펴봅니다. 그다음 사진·안내·홈페이지·광고 등 현재 매장에 필요한 작업을 제안합니다.

검색 순위나 매출을 보장하나요?

특정 검색 순위나 매출을 보장하지 않습니다. 작업 전후의 화면과 확인 가능한 고객 행동을 기록하고, 실제로 확인한 것과 추가로 살펴볼 것을 구분합니다.

비용과 계약 조건은 어떻게 확인하나요?

공통 공개 요금은 현재 검토 중입니다. 매장별 작업 범위와 일정, 비용·VAT, 착수 조건, 수정 횟수와 해지·환불 조건을 제안서에서 확인하고 합의한 뒤 확정합니다.

진단하면 연락처가 자동으로 전달되나요?

아니요. 체험과 자가진단 답변은 브라우저 메모리에서만 처리하며 자동 저장하거나 상담 시스템으로 보내지 않습니다. 직접 복사한 내용을 카카오톡에서 보내거나 별도로 문의해야 상담이 시작됩니다.

상담 다음에는 무엇을 하나요?

현재 상황과 함께 볼 채널을 확인하고 미팅 여부와 일정을 협의합니다. 미팅에서 실제 화면과 작업 우선순위를 살펴본 뒤, 범위와 조건이 담긴 제안을 검토합니다. 미팅 안내 화면은 계약이나 결제 신청이 아닙니다.
