01

요청과 범위

어떤 문제가 있고, 어디까지 바꿀까요?

현재 채널과 자료를 살펴보고 필요한 작업·제외 범위·일정을 정합니다.

남길 것

요청 정리 · 역할 분담 · 일정·비용 제안

02

자료와 기준

무엇을 사실로 쓸 수 있을까요?

운영 정보, 고객 제공 자료, 이미지 사용 허락을 확인합니다. 근거가 없는 성과는 넣지 않습니다.

확인할 것

사실 원본 · 자료 출처 · 사용·공개 허락

03

제작과 내부 검수

확인할 수 있는 초안이 있나요?

문안과 화면을 실제로 만들고, 합의한 기준으로 검수합니다. 변경 요청과 반영본을 연결해 남깁니다.

검토할 것

제작본 · 사실·권리 점검 · 화면·링크 확인

04

고객 검토와 승인

어느 버전을 확정했나요?

고객이 확인한 버전을 기준으로 수정·승인 기록을 구분합니다. 승인 범위가 바뀌면 다시 검토합니다.

확정할 것

승인한 파일·화면 · 수정 사항 · 승인 담당자

05

게시와 결과 확인

정한 위치에 제대로 반영됐나요?

합의한 채널에 반영한 뒤 표시 내용과 동작을 확인합니다. 게시 권한과 시점은 계약별로 정합니다.

기록할 것

게시 위치·일시 · 최종 표시 · 오류 조치

06

보고와 다음 작업

무엇이 달라졌고, 무엇을 더 볼까요?

실제로 확인한 변화와 아직 확인할 내용을 나눕니다. 측정 조건과 기간을 함께 남깁니다.

인계할 것

변경 이력 · 확인 가능한 결과 · 다음 점검

범위를 먼저 정합니다.

고객에게 공유할 자료와 공개할 사례

고객 검토용 자료와 홈페이지 공개 자료는 별도입니다. 고객명·사진·성과 수치의 공개 범위를 확인한 뒤 게시합니다.

원본·초안·승인본의 구분

원본과 수정본을 구분하고 확정한 버전을 남깁니다. 원본 제공 범위, 보존 기간, 종료 후 인계·삭제 방식은 계약 단계에서 협의합니다.

개인정보와 계정 접근

업무에 필요한 자료와 권한만 확인합니다. 개인정보 위탁, 계정 공유, 보관·삭제 조건이 필요한 업무는 별도 합의와 운영 검증을 거칩니다.
