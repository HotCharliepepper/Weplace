화면 검토공개 전 확인
가상 사례 구조 검토 · 실제 고객 사례가 아닙니다.

이 페이지의 문서 모형과 장면은 레이아웃 확인을 위해 코드로 만든 예시입니다. 실제 제작·납품·사용·성과나 공개 승인을 뜻하지 않습니다.

CASE LAYOUT / FICTIONAL FIXTURE

한 장의 안내가,
현장까지 이어지는 과정.

손님이 묻는 질문에서 출발해, 함께 정한 범위와 만든 결과물, 쓰이는 장면을 차례로 보여주는 상세페이지 구조입니다.

검토 대상: 이야기 순서와 증거의 자리
고객명 · 실제 현장 자료 · 내부 업무 정보 없음

  1. 01고객 질문

01 / THE QUESTION

처음 오는 손님은
무엇을 다시 물어볼까요?

사례는 현장의 질문에서 시작합니다.
누가, 어떤 장면에서, 무엇을 확인하려 했는지 보여줍니다.

가상 질문 · 실제 인용 아님

“처음 방문하는데,
어디에서부터 확인하면 될까요?”

처음 방문할 때 필요한 정보가 나뉘어 있는 상황을 가정한 예시입니다.

실제 사례에 들어갈 근거

확인 날짜, 해당 안내 화면, 반복 문의의 맥락을 적습니다. 대화 원문 대신 필요한 사실만 정리합니다.

질문을 추정한 경우에는 ‘가설’로 표시합니다. 고객의 말로 꾸미지 않습니다.

02 / AGREED SCOPE

같은 질문에 답하도록,
화면과 안내를 연결합니다.

합의한 작업과 제외한 작업을 함께 밝힙니다.
아래 범위는 레이아웃 예시이며 실제 합의가 아닙니다.

가상 범위 01

방문 전 보는 화면

고객이 찾아볼 정보를 어떤 순서로 정리할지 보여주는 자리입니다.

  • 대상 채널 · 수정 범위
  • 확인할 운영 정보
가상 범위 02

현장에서 보는 안내

화면과 같은 안내가 현장에서 어떻게 이어질지 보여주는 자리입니다.

  • 규격 · 제작 수량
  • 사용 장소 · 전달 방식
가상 범위 03

담당자가 쓰는 기준

안내가 바뀔 때 누가 무엇을 확인하는지 보여주는 자리입니다.

  • 책임자 · 검수 조건
  • 고객·타 제작자의 기여

증거가 필요한 곳: 합의 기록·날짜·범위·납품 수량·수정 조건. 세 영역을 항상 함께 제공한다는 서비스 약속이 아닙니다.

03 / WHAT WAS MADE

설명을 읽는 것보다,
만든 것을 볼 수 있도록.

실제 사례에서는 원본 파일과 검수된 화면을 보여줍니다. 여기서는 정보의 배치를 보기 위한 문서 모형만 사용합니다.

제안됨 / PROPOSAL

증거 미입력

제안 문서·제안일 필요. 제작이나 납품을 뜻하지 않습니다.

제작됨 / CREATED

증거 미입력

원본·버전·검수 기록 필요. 전달이나 사용을 뜻하지 않습니다.

납품됨 / DELIVERED

증거 미입력

전달일·대상·범위 확인 필요. 현재 사용 여부는 별도입니다.

현재 사용 중 / IN USE

증거 미입력

최근 사용 장면·확인일 필요. 과거 납품만으로 표시하지 않습니다.

이 네 단계는 사례의 증거를 구분하는 편집 기준입니다. 기존 FLOW의 업무 상태를 변경하거나 새로운 상태를 저장하지 않습니다.

04 / IN THE FIELD

어디에 놓이고,
누가 쓰는지도 보여줍니다.

완성된 파일과 실제 사용은 다른 사실입니다.
승인된 현장 기록으로 연결이 확인될 때만 보여줍니다.

실제 사용 증거 없음

승인된 현장 사진이
들어갈 자리

현재는 사진을 채우지 않습니다. AI 이미지·일러스트를 실제 사용 장면으로 대신하지 않습니다.

  • 사용 장소 · 확인일최근 기록인지, 현재도 같은 안내를 쓰는지 확인
  • 산출물과의 연결보이는 안내가 해당 버전의 제작물인지 확인
  • 보여도 되는 범위사람·연락처·명단·내부 메모·화면 권한 확인

05 / VERIFIED CHANGE

달라진 것은,
확인한 만큼만 이야기합니다.

실제 기록이 있는 반응과 변화만 보여줍니다.
근거가 없으면 제작물과 사용 장면에서 이야기를 마칩니다.

성과 데이터 · 고객 반응 미입력

이 가상 예시에는 확인된 성과가 없습니다.

수치, 평가, 고객의 인용문을 만들어 넣지 않습니다. 실제 사례의 다음 항목은 근거가 확보된 경우에만 공개합니다.

  • 정리 전후의 같은 화면과 확인 날짜
  • 실제 반응 기록과 인용 승인
  • 수치의 기간·기준·분모·출처와 해석의 한계
